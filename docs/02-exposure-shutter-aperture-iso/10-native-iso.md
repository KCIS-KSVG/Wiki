# 02.10 原生 ISO 与双原生 ISO

## 核心概念概述

原生 ISO 是传感器在未经过分信号放大时、处于最佳工作状态的基准感光度。在原生 ISO 下，相机能够获得最高的信噪比、最宽广的动态范围和最纯净的画质。

双原生 ISO 是部分高端相机搭载的技术——传感器内部设计了两套独立的信号放大电路，对应两个不同的原生感光度基准值。这一设计使得相机可以在不同光线条件下都工作在接近“最优”的状态，兼顾弱光拍摄能力与高画质需求。

理解原生 ISO 与双原生 ISO 的工作原理，有助于在不同光线条件下选择最优的感光度设定，最大化画质表现。

## 一、原生 ISO 的物理意义

### 传感器的最佳工作点

每个 CMOS 传感器在设计时都有一个最优的信号放大基准点，即原生 ISO。在该 ISO 设定下，传感器输出的信号被以最理想的方式放大——既充分提取了有效信号，又没有过度放大噪声。

原生 ISO 通常为 ISO 100 或 ISO 200，部分传感器可能为 ISO 64 或 ISO 160。在原生 ISO 下，相机的动态范围达到峰值，噪点水平最低，色彩还原最准确。

### 原生 ISO 与扩展 ISO 的区别

部分相机提供低于原生 ISO 的“扩展 ISO”选项，如 ISO 50（原生 ISO 100 的机型）。扩展 ISO 本质上是数字处理——相机以原生 ISO 拍摄后通过数字运算降低亮度，并非真正的物理感光度变化。

扩展 ISO 并不会带来比原生 ISO 更好的画质。相反，由于数字运算可能压缩高光细节，扩展 ISO 的动态范围往往低于原生 ISO。仅在极端强光下才考虑使用。

## 二、双原生 ISO 的技术原理

### 两套放大电路的并存

双原生 ISO 技术在传感器内部设计了两条独立的信号放大路径，分别对应高增益和低增益两种放大模式。

低增益路径对应较低的 ISO 基准值（如 ISO 100），在光线充足时使用，提供最优的动态范围和最低噪点。高增益路径对应较高的 ISO 基准值（如 ISO 800），在光线不足时切换使用，提供比传统单放大电路更优的高感表现。

### 增益切换的逻辑

当用户设定的 ISO 超过某一阈值时，相机自动从低增益路径切换至高增益路径。这一切换并非简单的“放大更多”，而是物理上切换到另一套放大电路，其基础噪声水平更低。

以搭载双原生 ISO 的机型为例：ISO 100-400 使用低增益路径（原生 ISO 100），ISO 800 及以上切换至高增益路径（原生 ISO 800）。在 ISO 800 下，该机型的噪点水平与传统机型 ISO 400 相当，但亮度提升了整整一档。

| 对比维度 | 传统单原生 ISO | 双原生 ISO |
| :--- | :--- | :--- |
| 放大电路 | 一套 | 两套（高增益/低增益） |
| 原生 ISO 数量 | 一个 | 两个 |
| 高感表现 | 随 ISO 升高噪点递增明显 | 切换后噪点水平回归较低状态 |
| 动态范围 | 持续下降 | 切换点附近保持较优状态 |
| 典型应用 | 绝大多数相机 | 高端微单、专业视频机 |

## 三、双原生 ISO 的实际应用场景

### 弱光环境拍摄

在室内体育赛事、音乐会、婚礼等弱光场景中，双原生 ISO 的优势极为明显。拍摄者可以将 ISO 设定在第二原生值（如 ISO 800 或 ISO 3200），获得的画质相当于传统机型低一档 ISO 的噪点水平，同时获得了更快的快门速度或更小的光圈设定空间。

### 视频拍摄中的持续优势

视频拍摄中 ISO 的设定更为关键，因为视频无法像照片那样通过后期降噪软件精细处理。双原生 ISO 使得视频机在高感光度下仍能保持可用的画质，特别适合纪录片、活动记录等无法补光的拍摄场景。

### 高动态范围场景

在某些高反差场景中（如室内窗边人像），双原生 ISO 允许拍摄者在保证高光不过曝的前提下，将 ISO 设置在第二原生值以获得更优的暗部噪点控制，后期提亮阴影时画质损失更小。

## 四、不同机型的双原生 ISO 实现差异

不同品牌的双原生 ISO 技术在实现方式和切换阈值上存在差异。

部分机型提供两档原生 ISO（如 ISO 100 和 ISO 800），切换点为 ISO 400-800 之间。部分专业电影摄影机提供三档原生 ISO，覆盖从低感到极端弱光的更宽范围。

高端机型在第二原生 ISO 下的噪点控制更为出色，切换过渡也更加平滑，无明显跳变痕迹。中端机型虽搭载双原生 ISO，但第二原生值下的动态范围缩减可能更为明显。

## 五、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：双原生 ISO 可以让任何 ISO 设定都获得同样纯净的画质。**

双原生 ISO 提供了两个“最优工作点”，而非所有 ISO 都同样优秀。在低增益路径内的 ISO 400 可能不如 ISO 100 纯净；在高增益路径内的 ISO 1600 可能不如 ISO 800 纯净。双原生 ISO 的优势在于“有两个高画质基准点”，而非“全程高画质”。

**误区二：扩展 ISO 也是原生 ISO 的一部分。**

扩展 ISO（如 ISO 50 或 ISO 102400）并非传感器物理工作状态，而是数字运算的结果。扩展 ISO 的动态范围、色彩还原和噪点表现均不如原生 ISO。仅在极端光线条件下，且无法使用其他曝光参数补偿时，才考虑启用扩展 ISO。

**误区三：只要开启自动 ISO，相机就会自动利用双原生 ISO 的优势。**

多数相机的自动 ISO 算法并不考虑原生 ISO 切换点。即使在光照充足时，相机也可能将 ISO 设定在略高于切换点的位置（如 ISO 500），而非使用更优的 ISO 400。手动控制 ISO、了解机型的切换阈值，才能充分发挥双原生 ISO 的优势。
:::

## 总结

原生 ISO 是传感器画质最优的工作点，双原生 ISO 则在传感器内部提供了两个这样的“最佳工作点”。理解自己相机的原生 ISO 设定和双原生切换逻辑，可以在不同光线条件下选择最优的 ISO 值，在保证曝光准确的同时最大化画质表现。
