# 02.06 光圈与 F 值控制

## 核心概念概述

光圈是镜头内部由多片叶片组成的可调节通光孔径。它通过收缩或扩张来控制进入相机的光线量，是曝光三角中第一个控制光线“入口”大小的环节。

光圈对画面的影响是双重的：它既直接决定了单位时间内的进光量（曝光），又深刻影响了画面的景深范围（背景虚化程度）。理解光圈的双重属性，是在各类拍摄场景中做出正确设定的基础。

## 一、光圈的工作原理

### 光圈叶片的机械结构

光圈由一组重叠排列的薄金属叶片构成，通过镜头内部的电磁或机械驱动机构控制叶片的开合程度。叶片完全张开时，通光孔径最大，进光量最多；叶片收缩时，通光孔径减小，进光量降低。

光圈的物理结构决定了它与镜头光学设计的紧密关系。镜头的最大光圈受限于前组镜片的直径和光学设计，这也是大光圈镜头价格昂贵的原因之一。

### F 值的计算逻辑

F 值（光圈值）是镜头焦距与通光孔径直径的比值，计算公式为：F = 焦距 ÷ 有效通光孔径。

F 值越小，通光孔径越大，进光量越多。F2.8 的通光孔径大于 F5.6，进光量是后者的四倍。

| F 值 | 通光量（相对值） | 通光孔径（相对） | 景深表现 |
| :--- | :--- | :--- | :--- |
| F1.4 | 最大 | 最大 | 最浅，背景极度虚化 |
| F2.0 | 约 F1.4 的一半 | 较大 | 很浅 |
| F2.8 | 约 F1.4 的四分之一 | 中等偏大 | 较浅 |
| F4.0 | 中等 | 中等 | 适中 |
| F5.6 | 中等偏小 | 中等偏小 | 较深 |
| F8.0 | 较小 | 较小 | 较深 |
| F11 及以上 | 小 | 小 | 最深，全画面清晰 |

完整的 F 值序列为：F1.4 - F2.0 - F2.8 - F4.0 - F5.6 - F8.0 - F11 - F16。相邻两档之间进光量相差一倍。

## 二、光圈对画面的双重影响

### 进光量控制

光圈开大（F 值减小），单位时间内进入相机的光量增加，画面变亮。光圈收缩（F 值增大），进光量减少，画面变暗。

在弱光环境中（室内活动、舞台演出），需要开大光圈以保证足够的进光量，配合适当的快门速度和 ISO。在强光环境中，需要收缩光圈以避免过曝。

### 景深控制

景深是指画面中“清晰范围”的深度。光圈越大（F 值越小），景深越浅，背景越模糊，主体越突出。光圈越小（F 值越大），景深越深，前后景都清晰。

景深控制是光圈在创作层面最重要的功能。人像摄影利用大光圈虚化杂乱背景，突出人物；风光摄影利用小光圈确保前景到远景都清晰，展现宏大场景。

## 三、不同场景的光圈选择策略

**人像与艺术摄影：** 选择大光圈（F1.4-F2.8）获得浅景深，虚化背景突出主体。需注意对焦精度——景深过浅时主体眼睛必须精准对焦，稍有偏差会导致面部失焦。

**风光与建筑摄影：** 选择小光圈（F8-F11）获得大景深，确保前景到远景都清晰。不建议使用 F16 或更小光圈，因为衍射效应会导致画面整体锐度下降。

**室内活动与会议记录：** 选择中等光圈（F2.8-F4）兼顾进光量与景深。既要保证快门速度足够（手持拍摄避免模糊），又要确保前后排人物都清晰。

**体育赛事（室内）：** 优先开大光圈（F2.8）以获取最大进光量，保证高速快门下曝光充足。景深较浅是次要问题——体育摄影的核心是拍到清晰瞬间。

**集体合影：** 选择 F5.6-F8 的中小光圈，确保前后排人脸都清晰。若场地光线允许，建议 F8 作为标准选择。

::: tip 💡 现场经验
在室内五楼体育馆拍摄篮球或排球赛事时，现场灯光往往偏暗，专业团队会将光圈开至镜头最大（F2.8 或 F1.8）。这不仅能获得更高的快门速度以冻结运动员动作，还能利用浅景深将背景的杂乱观众和广告牌虚化，使画面更简洁。若镜头最大光圈仅为 F4，则需提高 ISO 或降低快门速度来补偿。
:::

## 四、光圈与镜头素质的关系

### 最大光圈的光学挑战

镜头在全开光圈时，光线通过镜片边缘部分进入，这部分光线容易产生各种像差——色散（紫边）、球差（锐度下降）、暗角（边缘亮度降低）等。因此大多数镜头在最大光圈时并非光学素质最佳状态。

通常收缩 1-2 档光圈后，镜头锐度会明显提升，暗角减轻，色散减少。例如 F1.4 镜头在 F2.0-F2.8 时画质最佳。所谓“镜头的最佳光圈”，通常指最大光圈收缩两档左右的位置。

### 恒定光圈与浮动光圈变焦镜头

变焦镜头分为恒定光圈和浮动光圈两类。恒定光圈镜头在整个变焦范围内保持最大光圈不变，如 24-70mm F2.8 在任何焦段都可使用 F2.8。浮动光圈镜头的最大光圈随焦距变化，如 18-55mm F3.5-5.6 在广角端最大为 F3.5，长焦端降至 F5.6。

恒定光圈镜头通常光学素质更高、价格更昂贵，适合弱光和需要一致曝光的场景。浮动光圈镜头更轻便、便宜，适合日常拍摄。

## 五、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：光圈开到最大就能获得最好的人像效果。**

最大光圈下的浅景深确实能大幅虚化背景，但过浅的景深也可能导致主体部分失焦（鼻子清晰而眼睛模糊），且最大光圈时镜头锐度通常不是最佳。建议在需要极致虚化时使用最大光圈，但需注意对焦精度；在不需要极致虚化时收缩 1-2 档以获得更好画质。

**误区二：拍风光一定要用最小光圈。**

光圈收缩到 F16 或更小时，衍射效应开始显著降低画面锐度。风光摄影的标准做法是使用 F8-F11，兼顾景深和锐度。只有在需要极长曝光（如使用 ND 滤镜拍摄流水）时，才考虑使用更小光圈。

**误区三：F 值越小光圈越大，F 值越大光圈越小。**

这是对的。但需注意完整表达：“F2.8 比 F5.6 光圈大，进光量多”。F 值序列的“数字越小光圈越大”这一反直觉逻辑，初学者容易混淆，建议反复记忆。
:::

## 总结

光圈是曝光三角中唯一同时影响曝光量和画面视觉效果的参数。它通过控制通光孔径的大小，既决定了进光量（与快门速度、ISO 协同控制曝光），又深刻影响了景深的深浅。理解光圈的双重属性，是灵活控制画面虚实和营造视觉层次的核心能力。
