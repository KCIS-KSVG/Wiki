# 02 摄影曝光系统 概述

## 本章定位与学习目标

曝光是摄影中最基础也最核心的技术环节。一张照片的明暗程度、动态效果、噪点水平乃至整体氛围，都直接由曝光参数决定。曝光控制的核心三要素——光圈、快门速度、ISO感光度——构成了摄影中著名的“曝光三角”。

本章将从物理原理出发，逐一拆解每个要素的工作机制及其对画面的具体影响，并讲解三者如何协同配合以实现拍摄者的创作意图。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 曝光三角的“交换”关系

光圈、快门、ISO 三者共同决定曝光量。增大其中任何一个（光圈开大、快门变慢、ISO升高），曝光量增加；反之减少。在需要维持恒定曝光的前提下，调整其中一个参数必然需要调整另一个来补偿。例如，要获得更浅的景深（开大光圈），在保证曝光不变的情况下需要提高快门速度或降低ISO。

这种“交换”关系是曝光控制的核心逻辑，贯穿所有拍摄场景。

### 运动冻结与动态模糊的取舍

快门速度不仅影响进光量，更决定了运动物体在画面中的呈现方式。高速快门（如1/1000秒）能冻结快速运动的被摄体，适合体育赛事和动物抓拍。慢速快门（如1/30秒）会产生动态模糊，适合表现运动轨迹和流动感。

在室内体育场馆中，快门速度必须足够快以冻结运动员动作，同时还要考虑灯光频闪的同步问题。在音乐厅演出中，快门速度则需要在冻结演奏家手指动作和避免画面过暗之间取得平衡。

### 噪点控制与画质权衡

ISO 感光度决定了传感器信号放大的程度。ISO 越高，画面越亮，但同时放大了噪点信号。在光线充足时使用低ISO（如100-400）可获得最纯净的画质。在光线不足时，必须在提高ISO引入噪点和降低快门速度可能产生模糊之间做出取舍。

::: tip 💡 现场经验
在拍摄体育赛事时，专业团队优先保证快门速度足以冻结动作，通常设定在1/500秒以上，再根据光线条件调整光圈和ISO。若光圈已开至最大仍无法达到目标快门速度，则适当提高ISO来补偿，而非牺牲快门速度导致画面模糊。清晰度比噪点更重要——模糊的画面无法通过后期修复，而一定程度的噪点是可接受的。
:::
