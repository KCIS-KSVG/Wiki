# 02.08 什么是散景 Bokeh

## 核心概念概述

Bokeh 一词源于日语“ボケ”，意为“模糊”或“朦胧”。在摄影中，散景特指画面中焦外区域（即景深范围之外的模糊部分）的视觉呈现质量。

散景并非简单的“模糊”。优秀的散景能够为画面增添艺术氛围，使主体在柔和、平滑的背景衬托下更加突出；劣质的散景则可能呈现生硬、杂乱、令人分心的模糊效果。理解散景的构成因素，是镜头选择与创作控制的重要内容。

## 一、散景的视觉特征

### 散景的品质判断

优秀的散景具有以下视觉特征：过渡平滑自然，焦点区域到模糊区域之间没有明显边界；高光点呈现均匀的圆形或接近圆形，边缘柔和；焦外区域没有明显的轮廓线或“双重边缘”现象；整体感觉柔和、均匀、不杂乱。

劣质的散景则表现为：高光点呈现多边形或“洋葱圈”结构；模糊区域出现明显的线条或轮廓重影；背景中的点光源呈现边缘锐利的不规则形状；整体感觉生硬、杂乱、分散注意力。

### 散景的个性差异

不同镜头的散景风格各不相同。即使相同焦距、相同光圈的两支镜头，由于光学设计、镜片结构、镀膜工艺的差异，散景表现也可能截然不同。

部分镜头以“奶油般化开”的散景著称，焦外极其平滑，几乎看不出任何纹理。另一些镜头则以“旋涡散景”或“泡泡散景”为特色，焦外呈现旋转或气泡状的独特视觉效果，被部分摄影师视为艺术特征。

## 二、影响散景的核心因素

### 光圈叶片形状

光圈叶片的数量和形状直接影响焦外高光点的形状。叶片数量越多、排列越接近圆形，焦外光斑越圆润。奇数叶片产生的光斑为对称多边形，偶数叶片产生的光斑为对应边数的多边形。

现代高端镜头通常采用 9 片或 11 片圆形光圈叶片，在全开至收缩两档范围内都能保持近乎圆形的通光孔径，从而获得圆润的焦外光斑。

### 球面像差校正程度

球面像差是影响散景“柔软度”的关键光学像差。过度校正球面像差的镜头，焦外光斑边缘锐利，散景显得“硬”。球面像差欠校正或保留一定残差的镜头，焦外光斑边缘柔和，散景显得“软”。

这就是为什么某些老镜头虽然光学指标（分辨率、色散）不如现代镜头，但其散景风格却被许多摄影师钟爱——它们保留了独特的球差特征，产生了极具艺术感的焦外效果。

### 镜片结构与光路设计

镜头的整体光学结构，包括镜片数量、镜组排列方式、非球面镜片的使用等，共同影响散景的表现。复杂的光学结构（如反望远设计）可能在焦外产生“二线性散景”——模糊区域出现双重轮廓线。

| 影响散景的因素 | 产生优质散景的条件 | 产生劣质散景的条件 |
| :--- | :--- | :--- |
| 光圈叶片 | 圆形叶片，9片以上 | 多边形叶片，5-7片 |
| 球面像差 | 保留一定残差 | 过度校正或校正不足 |
| 镜片设计 | 简单对称结构 | 复杂结构导致二线性 |
| 镀膜工艺 | 均匀多层镀膜 | 镀膜不均或过厚 |

## 三、散景在不同场景中的应用

### 人像摄影中的散景

人像摄影是散景最常被讨论的领域。大光圈中长焦镜头（85mm F1.4、135mm F1.8 等）以浅景深配合柔和散景，将人物从背景中优雅剥离。优秀的散景使背景中的点光源呈现柔和圆润的光斑，绿叶变成均匀的色块，为画面增添氛围感。

### 舞台与演出摄影

在舞台演出拍摄中，背景通常包含复杂的灯光设备、幕布褶皱和音响装置。利用浅景深和柔和散景可以将这些元素虚化为色彩斑斓的光晕，使观众注意力集中在表演者身上。

### 静物与产品摄影

散景在静物摄影中用于分离主体与背景。通过控制光圈和拍摄距离，使主体清晰而背景柔和，突出产品的质感与细节。

## 四、如何判断镜头的散景品质

在实际选择镜头时，可以通过以下方法初步判断散景品质：

查看样片中的焦外光斑：在包含点光源（如树叶间隙的阳光、夜景灯光）的照片中观察焦外光斑的形状——圆形且边缘平滑为佳，多边形或边缘锐利为次。

观察过渡区域的平滑度：从焦点区域到完全模糊区域的过渡应该是渐进的、无明显边界的。若出现“双重边缘”或轮廓重影，说明二线性明显。

检查洋葱圈效应：劣质镜片加工精度不足时，焦外光斑可能出现同心圆状的“洋葱圈”纹理。这是非球面镜片研磨不均匀的典型表现。

## 五、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：散景就是背景越模糊越好。**

散景的核心是“模糊的质量”而非“模糊的程度”。背景极度模糊但生硬杂乱，不如适度模糊但平滑柔和。优质的散景是平滑的、均匀的、不分散注意力的，而不仅仅是“够虚”。

**误区二：昂贵的大光圈镜头一定有好的散景。**

价格与散景品质并非绝对正比。某些昂贵的现代镜头追求极致分辨率，过度校正像差，反而导致散景偏硬。而一些价格适中的老镜头或特殊设计镜头，可能在散景表现上更具艺术特色。

**误区三：散景的好坏完全主观，没有客观标准。**

散景确实包含审美偏好的主观成分，但也有一些客观判断依据：光斑形状是否圆润、过渡是否平滑、是否存在二线性或洋葱圈效应。优秀的散景在这些客观指标上都有出色的表现。
:::

## 总结

散景是摄影中兼具科学与艺术的领域。它由镜头光学设计、光圈叶片结构、球面像差校正程度等多重因素共同决定，直接影响画面的视觉氛围和情感表达。理解散景的构成因素和判断标准，有助于选择适合创作需求的镜头，并在实际拍摄中更有意识地利用焦外表现来强化画面感染力。
