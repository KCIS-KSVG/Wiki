# 21.05 SDI 广播级视频接口

## 核心概念概述

SDI（Serial Digital Interface，串行数字接口）是由美国电影与电视工程师协会（SMPTE）制定的专业数字视频传输标准[reference:0][reference:1]。它主要通过 75Ω 同轴电缆传输未压缩、未加密的数字视频信号，并可嵌入音频及时间码[reference:2]。

SDI 与 HDMI 的根本区别在于设计目标：HDMI 面向消费电子，追求“方便易用”；SDI 面向广播电视专业领域，追求“稳定可靠”[reference:3][reference:4]。从摄像机到切换台，从监视器到录机，SDI 是专业现场制播系统的主力[reference:5]。

## 一、SDI 的核心技术特点

### 未压缩传输：零延迟、零损耗

SDI 传输的是未压缩的数字视频信号[reference:6]。这意味着从信号源到显示端，画面不会因压缩而产生任何画质损失，也避免了压缩/解压缩过程带来的延迟[reference:7]。在需要实时切换的直播场景中，这一特性至关重要——导播按下切换按钮的瞬间，画面即时切换，观众不会感受到任何滞后。

### BNC 锁扣：连接可靠的物理保障

SDI 采用 BNC 锁扣式接头[reference:8]。一旦锁紧，线缆几乎不可能被意外拉扯脱落[reference:9]。在多机位直播现场，人员走动频繁、线缆纵横交错，HDMI 接头依靠摩擦力固定的设计极易被踢松导致信号中断，而 BNC 锁扣则从根本上杜绝了这一风险[reference:10]。

### 长距离传输：百米级无中继

SDI 专为长距离传输而设计[reference:11]。不同规格的 SDI 信号使用高质量同轴电缆的传输距离如下[reference:12]：

| 信号类型 | 典型传输距离 |
| :--- | :--- |
| SD-SDI（标清） | 最长 300 米 |
| HD-SDI（高清） | 最长 200 米 |
| 3G-SDI / 6G-SDI | 最长 100 米 |
| 12G-SDI（4K） | 最长 80 米 |

这一特性使 SDI 在大型演播室、体育场馆和音乐厅等场地中具有不可替代的优势——摄像机可架设在舞台附近，控制室可设在远离舞台的后方或二楼，两者之间通过一根 SDI 线缆即可完成信号传输。

## 二、SDI 规格标准

SDI 标准自诞生以来经历了多次迭代，每一次升级都在带宽和分辨率支持上实现跨越[reference:13][reference:14]。

| 规格 | 带宽 | 最高分辨率 | 推出年份 | 对应标准 |
| :--- | :--- | :--- | :--- | :--- |
| SD-SDI | 270 Mbps | 480i / 576i | 1989 | SMPTE 259M |
| HD-SDI | 1.485 Gbps | 720p / 1080i | 1998 | SMPTE 292M |
| 3G-SDI | 2.97 Gbps | 1080p@60fps | 2006 | SMPTE 424M |
| 6G-SDI | 6 Gbps | 4K@30fps | 2015 | SMPTE ST 2081 |
| 12G-SDI | 12 Gbps | 4K@60fps | 2015 | SMPTE ST 2082 |

### SD-SDI：标清时代的奠基者

SD-SDI 是 SDI 标准的最初版本，数据速率为 270 Mbps[reference:15]。它支持标清视频格式（480i/576i），对应 SMPTE 259M 标准[reference:16]。虽然标清时代已成过去，但 SD-SDI 奠定了 SDI 的技术框架——未压缩传输、同轴电缆、BNC 接口，这些核心特征至今未变。

### HD-SDI：高清时代的开启

HD-SDI 的数据速率为 1.485 Gbps[reference:17]，支持 720p 和 1080i 分辨率[reference:18]。HD-SDI 是高清演播室的标准配置，目前仍在大量使用。

### 3G-SDI：全高清的终极方案

3G-SDI 的数据速率为 2.97 Gbps[reference:19]，是 HD-SDI 的两倍。它支持 1080p@60fps 的全高清传输[reference:20]。3G-SDI 是当前 SDI 应用中最主流的规格之一，广泛应用于电影制作和现场直播[reference:21]。

### 6G-SDI 与 12G-SDI：4K 超高清时代

6G-SDI 和 12G-SDI 是 2015 年发布的标准，专为 4K 超高清制作设计[reference:22]。6G-SDI 支持 4K@30fps，12G-SDI 支持 4K@60fps[reference:23][reference:24]。

12G-SDI 的核心价值在于“单根线缆搞定 4K”——在 12G-SDI 出现之前，传输 4K 信号需要 4 根 HD-SDI 线缆或两根 6G-SDI 线缆。12G-SDI 将 4 路 HD-SDI 信号合并到单根线缆中，大幅简化了现场布线[reference:25]。

## 三、SDI 与 HDMI 的核心对比

SDI 与 HDMI 是视频传输领域的两大标准，分别服务不同的应用场景[reference:26]。

| 对比维度 | SDI | HDMI |
| :--- | :--- | :--- |
| 主要市场 | 专业广播、影视制作、直播 | 消费电子（电视、游戏机、笔记本） |
| 传输距离 | 3G-SDI 可达 100 米 | 通常不超过 15 米 |
| 连接器 | BNC（锁扣式，防脱落） | 无锁扣，依靠摩擦力固定 |
| 信号类型 | 串行传输[reference:27] | 并行传输[reference:28] |
| 设备发现 | 即插即用，单向传输 | 支持双向通讯，自动识别设备 |
| 适用场景 | 演播室、大型活动现场、长距离传输 | 家庭影音、小型工作室、近距离监看 |

SDI 的核心优势在于长距离稳定传输和连接可靠性。在演唱会、体育赛事等大型现场活动中，SDI 是保证信号不中断的标准方案[reference:29][reference:30]。而 HDMI 的优势在于普及度高、支持双向通讯（设备可自动交换信息），适合消费级设备和近距离连接[reference:31]。

## 四、SDI 在摄影与视频制作中的应用

### 多机位直播：SDI 是主力

在多机位直播制作中，SDI 是信号传输的标准方案。摄像机通过 SDI 将画面传输至导播台，导播台切换后将节目信号通过 SDI 输出至录像机或推流设备。ATEM SDI 系列导播台配备多路 SDI 输入和输出接口，支持多机位信号的同时处理[reference:32]。

### 长距离信号传输：摄像机到控制室

在音乐厅、体育场馆等大型场地中，摄像机通常架设在舞台附近，控制室位于观众席后方或二楼。两者之间的距离往往超过 HDMI 的有效传输范围，SDI 的百米级传输能力使其成为唯一可靠的选择[reference:33]。

### 专业监视器与录机

专业现场监视器通常同时配备 SDI 和 HDMI 输入接口，但在需要长距离信号传输或极高可靠性的场景中，SDI 是首选。外置录机（如 Atomos 系列）同样支持 SDI 输入，用于高质量视频的现场录制[reference:34]。

### 4K 制作与 12G-SDI

在 4K 超高清制作中，12G-SDI 是当前的标准方案。单根 12G-SDI 线缆即可传输 4K@60fps 信号[reference:35]，无需多根线缆的复杂配置。12G-SDI 提供高带宽、低延迟，适合长距离布线，是广播和视频制作环境向 4K 和 HDR 过渡时的首选接口[reference:36]。

## 五、选购与使用建议

### 确认设备接口规格

不同设备支持的 SDI 规格不同。一台摄像机可能支持 3G-SDI 输出，而导播台可能支持 12G-SDI 输入。在连接前需确认双方的 SDI 规格是否匹配，或向下兼容。

### 线缆与接头质量

SDI 线缆应选择 75Ω 阻抗的同轴电缆[reference:37]。专业级线缆（如 Belden 1694A）采用双层屏蔽设计，适合长距离传输[reference:38]。BNC 接头建议选择镀金接口和压接式工艺，避免松动导致信号中断[reference:39]。

### 传输距离的权衡

不同 SDI 规格的传输距离不同。3G-SDI 可稳定传输 100 米，12G-SDI 的传输距离约为 80 米[reference:40]。在需要更长距离的场景中，可使用 SDI 光纤延长器将电信号转换为光信号，突破铜缆的距离限制[reference:41]。

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：SDI 和 HDMI 可以互换使用，只需要一个转接头。**

SDI 和 HDMI 的信号格式、阻抗和电气特性均不同。虽然存在 SDI 转 HDMI 的转换器，但转接头本身无法完成信号转换——必须使用有源转换设备（如 SDI-HDMI 转换盒）。直接使用物理转接头连接 SDI 和 HDMI 设备无法工作。

**误区二：HDMI 的信号质量比 SDI 差。**

HDMI 和 SDI 在短距离内均可传输高质量、未压缩的数字信号。两者的核心差异在于传输距离、连接可靠性和应用场景，而非信号质量本身。SDI 的优势在于“长距离也能保持高质量”，而非“短距离比 HDMI 更好”。

**误区三：所有 SDI 线缆都一样，买最便宜的就行。**

不同质量的 SDI 线缆在传输距离和信号稳定性上有显著差异。劣质线缆可能导致信号衰减、画面闪烁甚至完全无法传输。在关键项目中，应选择符合规格的专业级线缆（如 Belden 系列）。

**误区四：12G-SDI 线缆可以向下兼容所有低规格 SDI 信号。**

12G-SDI 线缆确实可以传输 HD-SDI 和 3G-SDI 信号。但反之不成立——普通 3G-SDI 线缆可能无法稳定传输 12G-SDI 信号，导致 4K 画面出现马赛克或黑屏。
:::

## 总结

SDI 是广播级视频制作的核心传输标准。它以未压缩传输保障零延迟、零损耗，以 BNC 锁扣保障连接可靠，以百米级传输距离满足大型现场的布线需求。从 SD-SDI 到 12G-SDI，SDI 标准持续演进以适应从标清到 4K 超高清的制作需求。在多机位直播、音乐厅演出、体育赛事等对信号稳定性和长距离传输要求严苛的场景中，SDI 是不可替代的传输方案。
