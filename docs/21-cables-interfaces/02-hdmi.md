# 21.02 HDMI 2.0 与 2.1 版本区别

## 核心概念概述

HDMI（High-Definition Multimedia Interface）是目前最普及的数字音视频接口标准。自 2002 年发布以来，HDMI 经历了多个版本的迭代，其中 HDMI 2.0 和 2.1 是近年来最重要的两个版本。

HDMI 2.1 并非对 2.0 的简单修补，而是一次从带宽到功能的全面跃升。其核心差异在于带宽的巨大提升以及由此带来的高分辨率、高刷新率和一系列先进特性。理解两者的差异，是在相机、监视器、导播台和显示设备之间选择正确连接方案的基础。

## 一、带宽与分辨率

### 带宽的跨越式提升

HDMI 2.0 的最大带宽为 **18 Gbps**，足以支持 4K@60Hz 的视频传输。HDMI 2.1 的最大带宽提升至 **48 Gbps**，是 2.0 版本的 2.67 倍。

这一带宽的提升使 HDMI 2.1 能够支持更高的分辨率和刷新率组合。

### 分辨率与刷新率支持

| 分辨率 | HDMI 2.0 | HDMI 2.1 |
| :--- | :--- | :--- |
| 4K@60Hz | 支持 | 支持 |
| 4K@120Hz | 不支持 | 支持 |
| 8K@30Hz | 不支持（需压缩） | 支持 |
| 8K@60Hz | 不支持 | 支持 |
| 10K@60Hz | 不支持 | 支持（需 DSC 压缩） |

对于摄影和视频制作而言，HDMI 2.1 的 4K@120Hz 支持意味着在高端监视器上可以更流畅地预览高帧率素材；8K 支持则为未来的 8K 制作提供了连接基础。

## 二、HDR：静态 vs 动态

### HDMI 2.0：静态 HDR

HDMI 2.0 支持静态 HDR（如 HDR10），即在整个视频播放过程中使用固定的元数据（亮度、色彩信息）来指导显示设备。这种方式的局限性在于：同一视频中不同场景的亮度差异较大时，无法针对每个场景单独优化。

### HDMI 2.1：动态 HDR

HDMI 2.1 支持**动态 HDR**，包括 HDR10+ 和 Dolby Vision 等格式。动态 HDR 允许对视频的每一帧或每一场景进行独立的亮度、对比度和色彩优化，使画面细节和色彩表现更加精准。

对于专业调色和监看来说，动态 HDR 可提供更接近人眼真实观看体验的参考画面。

## 三、eARC：增强型音频回传通道

### ARC（音频回传通道）

HDMI 2.0 支持 ARC（Audio Return Channel），允许电视将音频信号通过 HDMI 线缆回传至功放或音响系统。但 ARC 的带宽有限，仅支持压缩的 5.1 声道音频，无法传输高品质的无损音频格式。

### eARC（增强型音频回传通道）

HDMI 2.1 引入 eARC（Enhanced Audio Return Channel），带宽大幅提升，支持**高比特率、无压缩的音频格式**，包括 Dolby Atmos、DTS:X 等沉浸式音频格式。eARC 还支持音频格式的自动检测和配置，简化了设备连接设置。

在视频制作中，eARC 对于需要从显示设备回传高品质音频到监听系统的场景具有实用价值。

## 四、游戏与媒体增强特性

HDMI 2.1 引入了一系列针对游戏和动态媒体优化的新特性，这些特性同样对视频播放和预览有参考价值。

| 特性 | 全称 | 功能 |
| :--- | :--- | :--- |
| VRR | 可变刷新率 | 减少或消除画面撕裂、卡顿和延迟，使画面更平滑 |
| ALLM | 自动低延迟模式 | 自动将显示设备切换到最低延迟的游戏模式 |
| QFT | 快速帧传输 | 减少帧传输延迟，降低输入延迟 |
| QMS | 快速媒体切换 | 消除切换不同视频源时的黑屏时间 |

在视频制作中，VRR 和 ALLM 对于在监视器上预览高动态素材时保持流畅和低延迟具有辅助价值。

## 五、线缆要求

### 线缆类型

| 线缆类型 | 支持版本 | 带宽 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 标准 HDMI 线缆 | HDMI 1.4 及以下 | 约 5 Gbps | 1080p 视频 |
| 高速 HDMI 线缆 | HDMI 2.0 | 18 Gbps | 4K@60Hz |
| 超高速 HDMI 线缆 | HDMI 2.1 | 48 Gbps | 8K@60Hz、4K@120Hz |

要发挥 HDMI 2.1 的全部性能，**必须使用通过认证的“超高速 HDMI 线缆”**（Ultra High Speed HDMI Cable）。该线缆支持 48Gbps 带宽和所有新特性，并向下兼容旧设备。

### 线缆长度的限制

与 HDMI 2.0 类似，HDMI 2.1 的超高速线缆在超过 3-5 米后信号衰减明显。对于超过 5 米的长距离传输，建议使用**光纤 HDMI 线缆**或有源 HDMI 线缆。

## 六、实际应用中的选择建议

### 相机外接监视器

大多数相机和外接监视器目前仍以 HDMI 2.0 为主（支持 4K@60Hz）。对于需要监看 4K@60Hz 画面的拍摄场景，HDMI 2.0 已足够。若未来需要 8K 或 4K@120Hz 监看，则需设备双方均支持 HDMI 2.1。

### 导播台连接

ATEM Mini 等小型导播台的 HDMI 接口多为 2.0 版本，支持 4K@60Hz 输入和输出。对于 4K 多机位直播制作，HDMI 2.0 已满足需求。若涉及 8K 信号，需升级至支持 HDMI 2.1 的设备。

### 现场大屏

若现场大屏支持 8K 或 4K@120Hz，且信号源同样支持，则应使用 HDMI 2.1 超高速线缆连接。若大屏仅支持 4K@60Hz，HDMI 2.0 即可满足。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：标称“4K 高清线”就支持 HDMI 2.1 的所有功能。**

“4K 高清线”通常仅指支持 4K@60Hz（即 HDMI 2.0 规格）。要支持 8K 或 4K@120Hz，必须使用明确标注“超高速 HDMI 线缆”并通过认证的产品。

**误区二：HDMI 2.1 设备使用普通高速线缆也能达到 8K。**

普通高速 HDMI 线缆的带宽为 18Gbps，无法满足 8K@60Hz 所需的 48Gbps。即使设备和显示器都支持 8K，线缆也会成为瓶颈，导致黑屏或降级显示。

**误区三：HDMI 2.1 的所有特性都必须同时开启。**

VRR、ALLM、QFT 等特性需要信号源和显示设备双方同时支持。在实际连接中，系统会自动协商支持的功能，无需手动配置。

**误区四：HDMI 线缆长度越长越好。**

超过 5 米的铜芯 HDMI 线缆信号衰减明显，可能导致画面闪烁或黑屏。长距离传输应使用光纤 HDMI 线缆或有源线缆。
:::

## 总结

HDMI 2.1 相比 2.0 版本的升级是跨越式的：带宽从 18Gbps 提升至 48Gbps，分辨率从 4K@60Hz 提升至 8K@60Hz 或 4K@120Hz，HDR 从静态升级为动态，音频回传从 ARC 升级为 eARC，并引入了 VRR、ALLM 等游戏优化特性。在摄影和视频制作中，HDMI 2.1 为 8K 监看、高帧率预览和高质量音频回传提供了连接基础。选购线缆时，应认准“超高速 HDMI 线缆”认证，并根据传输距离选择合适的线缆类型。
