# 21 摄影连接线缆与接口知识 概述

## 本章定位与学习目标

在摄影与视频制作中，线缆和接口是连接设备、传输信号、供电和数据的基础设施。一根不匹配的线缆可能导致信号丢失、分辨率下降、录制中断，甚至损坏设备；一个不兼容的接口可能让你在现场束手无策。

HDMI、USB-C、Thunderbolt、SDI、XLR——每一种接口都有其设计目标、性能边界和适用场景。理解这些接口和线缆的技术规范与选择逻辑，是在现场快速搭建拍摄系统、排查故障、保证信号质量和设备安全的基础。本章将系统讲解摄影中常见连接线缆与接口的知识体系。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 接口选择决定系统架构上限

在多机位直播中，选择 HDMI 还是 SDI 直接决定了传输距离和信号稳定性。HDMI 适合短距离（5-15米）连接，价格便宜但无锁扣、易脱落；SDI 适合长距离（50-100米以上）传输，BNC 锁扣确保连接可靠。在音乐厅演出、校园活动直播等需要远距离信号传输的场景中，SDI 是唯一可靠的选择。

### USB-C 的“多功能陷阱”

USB-C 是物理接口形态，同一接口可能支持不同的底层协议——USB 3.2 Gen 1（5Gbps）、USB 3.2 Gen 2（10Gbps）、USB 3.2 Gen 2x2（20Gbps）、Thunderbolt 3/4（40Gbps）。一根线缆可能只支持充电和数据传输，但不支持视频输出。在连接设备前，务必确认设备和线缆双方支持的协议版本。

### 线缆质量是信号完整性的保障

劣质线缆可能导致信号衰减、干扰、甚至设备损坏。在需要长距离传输或高带宽场景中（如 4K 视频传输、高速数据拷贝），应选择符合规范、线径足够的高品质线缆。
