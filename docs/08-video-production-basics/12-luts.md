# 08.12 LUT预设的使用

## 核心概念概述

LUT是Look-Up Table的缩写，直译为“查找表”。在视频调色中，LUT是一个预设的色彩转换配置文件——它告诉调色软件如何将输入的颜色值映射为输出的颜色值，从而快速实现色彩风格或技术性色彩转换。

LUT是连接Log视频与最终成片之间的桥梁。它既可以作为技术工具，将Log画面还原为标准色彩空间，也可以作为创作工具，为画面添加特定的色彩风格和情绪。

## 一、LUT的基本概念

### LUT的工作原理

LUT本质上是一个数学查找表。输入一个颜色值，LUT输出另一个颜色值。例如，输入RGB值（100,50,30），LUT输出（120,55,35）。这个映射关系由LUT文件预先定义，调色软件读取LUT并应用到素材上。

### LUT的广泛应用

LUT广泛应用于视频制作的多个环节：拍摄时加载到外接监视器上，将Log画面转换为可判断的预览画面；剪辑时在软件中应用LUT，快速还原Log素材或进行风格化处理；实时直播推流时应用LUT，让直播画面呈现特定色彩风格。

## 二、LUT的主要类型

### 技术LUT

技术LUT用于标准的色彩空间转换，将Log素材从对数伽马转换为Rec.709标准色彩空间。它帮助校正灰平的Log画面，恢复正常的对比度和饱和度，得到基础的“干净”画面。

不同品牌和不同Log曲线需要对应的还原LUT。例如S-Log3素材需使用S-Log3转Rec.709的LUT；C-Log素材需使用C-Log转Rec.709的LUT；V-Log素材需使用V-Log转Rec.709的LUT。

技术LUT本身不创造特定风格，只做标准化转换，是调色的起点。

### 创意LUT

创意LUT在技术还原的基础上叠加了特定的色彩风格。常见的创意风格包括胶片模拟、电影感色调、日系清新、复古风格、黑白转换和高饱和度鲜艳风格。

创意LUT可根据项目风格直接应用或作为调色的起点。

### 监看LUT

监看LUT用于拍摄时实时预览，帮助判断Log素材的曝光和构图。监看LUT通常不记录到素材中，仅用于现场监视器或电子取景器的显示。

## 三、LUT的应用场景

**拍摄监看：** 在外接监视器上加载监看LUT，现场判断曝光和构图。选择与相机Log曲线匹配的还原LUT，或根据导演意图加载风格化LUT进行现场预览。

**后期剪辑：** 在剪辑软件中对Log素材应用技术LUT进行基础还原。将还原LUT作为调色起点，在此基础上添加创意LUT或手动调色。

**多机位色彩匹配：** 在DaVinci Resolve中为不同品牌Log素材分别应用对应的技术LUT，统一转换至同一色彩空间后再进行手动微调，使各机位色彩一致。

## 四、LUT的获取与选择

**官方LUT**：相机品牌官方提供，质量可靠，与对应的Log格式完全匹配。多数品牌在其官方网站提供免费下载，建议优先使用。

**第三方LUT**：第三方厂商和调色师开发的LUT风格多样，可以快速实现特定风格。质量参差不齐，需试用后选择。

**自制LUT**：在达芬奇等调色软件中手动调色后，可将调色结果导出为LUT，供其他项目或机位复用。

## 五、LUT使用的工作流建议

| 阶段 | LUT类型 | 作用 |
| :--- | :--- | :--- |
| 拍摄监看 | 监看LUT | 现场预览色彩和曝光 |
| 后期还原 | 技术LUT | Log → Rec.709标准转换 |
| 风格化 | 创意LUT | 叠加风格色调 |
| 多机位统一 | 技术LUT+手动微调 | 色彩一致 |

## 六、LUT使用的注意事项

使用前确认素材的Log格式与LUT匹配，避免混用导致色彩错误。不同品牌的Log曲线差异显著，混用会产生严重色偏。

注意曝光对LUT效果的影响。LUT基于标准曝光设计，欠曝或过曝素材应用LUT后效果可能不理想，应先校正曝光再应用LUT。

建议先应用技术LUT进行基础还原，再叠加创意LUT，确保良好的调色起点。多个LUT叠加时注意顺序。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：LUT可以修复任何曝光或色彩错误。**

LUT只能进行色彩映射，无法恢复拍摄时丢失的高光或暗部细节。素材严重欠曝或过曝时，LUT无法“修复”画面。正确曝光是LUT效果的前提。

**误区二：所有LUT都可以通用，不需要区分素材类型。**

不同Log格式需要对应的还原LUT。将S-Log3素材套用V-Log还原LUT会产生错误的色彩和对比度，效果不可预期。

**误区三：LUT就是最终调色，不需要再手动调整了。**

LUT是调色的起点，而非终点。应用LUT后通常仍需进行曝光微调、饱和度调整和二次调色，才能使画面达到最佳效果。
:::

## 总结

LUT是连接Log素材与最终成片之间的色彩转换工具。技术LUT实现色彩空间的标准化转换，创意LUT叠加特定的艺术风格。在拍摄监看、后期还原和风格化创作中，合理使用LUT可显著提高视频制作的色彩管理效率和风格化表达的能力。
