# 08.13 视频动态范围

## 核心概念概述

动态范围是指视频画面中从最暗到最亮区域之间的亮度差异范围。动态范围越宽广，画面中能够同时保留的高光细节和暗部细节就越多——天空的云层纹理和阴影中的物体可同时清晰可见。

理解动态范围的物理意义及其对画质的影响，是在高反差场景中制定合理拍摄策略，以及理解Log视频、HDR等技术概念的基础。

## 一、动态范围的基本概念

### 动态范围的定义

动态范围以“档”或“级”为单位，表示传感器或视频格式能够记录的最亮信号与最暗信号之间的比值。动态范围越高，传感器能够同时记录的亮度层级越多，高光和暗部的细节保留越丰富。

### 动态范围的实际意义

在高反差场景中（如室内窗边人像、舞台聚光灯下的表演者、日落时的风光），画面同时包含极亮和极暗的区域。低动态范围设备无法同时保留两端的细节——要么高光过曝（死白），要么暗部欠曝（死黑）。高动态范围设备可同时保留两端的细节。

## 二、不同设备的动态范围

| 设备类型 | 典型动态范围 | 说明 |
| :--- | :--- | :--- |
| 智能手机 | 约10-11档 | 算法多帧合成可提升 |
| 入门级相机 | 约11-12档 | 满足日常拍摄 |
| 专业微单/单反 | 约12-13档 | 静态照片可达14档以上 |
| 专业摄影机 | 约14-16档 | Log模式下可充分利用 |
| 人眼 | 约20档以上 | 远超任何传感器 |

人眼的动态范围远高于任何相机传感器——这是为什么在拍摄高反差场景时，相机记录的远不如人眼所见丰富的原因。Log格式的引入就是为了尽可能缩小这一差距。

## 三、动态范围与Log视频的关系

Log视频是最大化利用传感器动态范围的核心手段。标准视频（Rec.709）在拍摄时已将动态范围压缩至约6-8档，高光和暗部细节被丢弃。Log模式保留传感器捕捉的全部动态范围（约12-15档），为后期提供充足的调整空间。

Log曲线的暗部和中间调分配更多数据位，高光区域压缩，保留高光细节的同时保护暗部信息。Log并不提升传感器的物理动态范围，而是改变数据映射方式，更充分地利用传感器已有的动态范围。

## 四、HDR与SDR

### SDR（标准动态范围）

SDR是目前大多数视频的交付标准，动态范围约6-8档，亮度范围为0.1-100尼特。SDR视频在标准显示器上播放，色彩空间为Rec.709。多数网络视频、电视节目和活动记录仍为SDR交付。

### HDR（高动态范围）

HDR是新一代视频标准，动态范围更广（10档以上），亮度范围可达0.001-1000尼特甚至更高。HDR视频需要专用的HDR显示器和支持HDR的播放设备才能呈现完整效果。

HDR格式包括HDR10、HDR10+、Dolby Vision和HLG。HLG常用于广播级制作，兼容SDR和HDR显示设备。在HDR中，高光细节（如阳光反射、灯光）呈现更丰富，暗部细节更清晰。

## 五、动态范围的优化策略

**拍摄阶段：** 使用Log模式拍摄保留最宽的动态范围，采用ETTR曝光策略（高光优先不过曝），配合波形图或斑马纹确保高光细节保留。

**格式选择：** 优先选择10-bit或更高色深的格式，RAW格式提供最大的后期动态范围调整空间。

**后期处理：** 利用调色软件的动态范围压缩工具将Log素材映射为Rec.709或HDR输出。HDR输出时应用HDR色彩空间转换。

## 六、不同场景的动态范围需求

**室内会议/访谈（光线均匀）：** 动态范围需求较低，SDR标准已足够，Log并非必需。

**音乐厅/舞台演出（聚光灯）：** 动态范围需求中等偏高，建议使用Log模式保留高光和暗部细节。

**户外晴天（高反差）：** 动态范围需求最高，必须使用Log模式或HDR格式才能保留完整细节。

**HDR项目交付：** 需全程使用Log或RAW拍摄，后期在HDR色彩空间中完成调色。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：动态范围只由传感器决定，与拍摄格式无关。**

传感器决定了物理动态范围上限，但拍摄格式（Log vs 标准）决定了这个上限有多少被保留。标准视频在拍摄时即丢弃了部分动态范围，Log则完整保留。

**误区二：HDR视频在普通显示器上观看时效果比SDR差。**

HDR视频在SDR显示器上播放时，播放器会进行色调映射将其压缩为SDR范围，效果与原生SDR视频接近但可能略逊于针对SDR优化的版本。HDR的优势需要在HDR显示器上才能充分体现。

**误区三：动态范围越高，画面一定越好看。**

高动态范围提供了更多信息，但最终画面的美感取决于曝光控制、调色和构图。动态范围只是技术基础，不等于视觉上的“好看”。
:::

## 总结

动态范围是衡量视频明暗信息记录能力的关键指标。Log模式可充分利用传感器的动态范围潜力，HDR是新一代高动态范围交付标准。在高反差场景中，动态范围的优化直接影响画面中高光和暗部细节的保留程度。
