# 08.03 帧率选择

## 核心概念概述

帧率是视频拍摄的基本参数之一，它决定了每秒钟记录的画面帧数，直接影响了视频的流畅度、运动表现风格和观众观看感受。

不同的帧率服务于不同的创作目的——24fps追求电影感，25fps适配电视制式，50fps以上提供极致流畅。理解帧率的视觉差异与选择逻辑，是视频创作的必修课。

## 一、常见帧率及其特点

### 24fps：电影工业标准

24fps是电影行业沿用近百年的标准帧率。其特点是相邻帧间存在适度的运动模糊，画面具有“胶片感”和“电影感”，是叙事电影、短片和创意视频的首选。

24fps下每帧曝光时间较长，在弱光环境中比高帧率更容易获得充足曝光。

### 25fps：PAL制式标准

25fps是PAL制式电视系统（中国大陆、欧洲、澳大利亚等地区）的标准帧率。它提供了与24fps相近的电影感，同时适配地区电视播出标准，是中国大陆网络视频和活动记录最常用的帧率。

### 30fps：NTSC制式标准

30fps（实际为29.97fps）是NTSC制式电视系统的标准帧率，主要应用于北美和日本地区。画面比24/25fps略流畅，适合电视节目和北美市场的网络内容。

### 50fps与60fps：高帧率

50fps（PAL地区）和60fps（NTSC地区）提供了更高的时间分辨率，画面极为流畅，适合体育赛事、高速运动和需要慢动作处理的场景。播放时可进行慢动作处理（放慢至25fps播放，获得两倍慢动作）。

### 120fps及以上：超高速帧率

120fps、240fps甚至更高帧率专为慢动作拍摄设计。在25fps时间线上播放，120fps素材可获得约5倍慢动作效果。适合极限运动、动作细节捕捉和高速摄影创作。

## 二、帧率的视觉风格对比

| 帧率 | 运动模糊 | 视觉风格 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 24fps | 较多 | 电影感、梦幻 | 叙事短片、创意视频 |
| 25fps | 适中 | 自然流畅 | 活动记录、网络视频 |
| 30fps | 较少 | 平滑清晰 | 电视节目、直播 |
| 50/60fps | 较少 | 极致流畅 | 体育赛事、运动捕捉 |
| 120fps+ | 极轻 | 慢动作素材 | 极限运动、特效 |

## 三、制式选择：PAL vs NTSC

全球视频制式分为两大体系：PAL（25fps，50Hz电网）和NTSC（30fps，60Hz电网）。

在中国大陆（PAL制式，50Hz电网）拍摄时，选择PAL制式可避免室内灯光频闪问题，25fps与50fps系列帧率适配本地播出标准。

在混合制式环境中（如进口设备默认NTSC），需确认制式设置，避免混剪时产生帧率转换问题。多机位项目必须确保所有机位制式一致。

## 四、帧率与快门速度的配合

帧率与快门速度的配合决定了运动模糊的自然程度（详见08.04快门角度）。标准配合是快门速度为帧率的两倍分之一，即180度快门原则：25fps使用1/50s快门，50fps使用1/100s快门。

在光线不足时，在25fps下可使用更慢的快门速度（如1/25s或1/30s）来增加进光量，但需注意运动模糊显著增加，且可能产生闪烁感。

在体育赛事拍摄中，快门速度可能高于180度原则（如1/500s以上），以冻结高速动作，但会牺牲自然运动模糊。

## 五、帧率选择速查表

| 场景 | 推荐帧率 | 快门速度（180度） | 说明 |
| :--- | :--- | :--- | :--- |
| 叙事短片/创意视频 | 24fps | 1/48s（约1/50s） | 电影感优先 |
| 活动记录/会议 | 25fps | 1/50s | PAL制式标准 |
| 音乐会/舞台演出 | 25fps | 1/50s | PAL制式，自然流畅 |
| 体育赛事 | 50fps | 1/100s | 高流畅度，捕捉动作 |
| 慢动作素材 | 100/120fps+ | 1/200s或更高 | 后期放慢处理 |
| 直播推流 | 25fps或30fps | 1/50s或1/60s | 平台兼容性优先 |

## 六、多机位项目的帧率要求

在多机位拍摄中，所有机位的帧率必须完全一致。帧率不一致的素材在后期多机位剪辑中无法对齐，会导致声画不同步和画面跳动。

在音乐厅、阶梯教室等场景中，需在进场前统一所有机位的制式和帧率设定，主机位设定后，其他机位以主机位为基准统一设置。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：24fps一定比25fps更有电影感。**

24fps和25fps的视觉差异极小，普通人难以察觉。在中国大陆选择25fps可避免与灯光频闪的兼容问题，同时获得几乎相同的电影感效果。

**误区二：帧率越高视频质量越好。**

高帧率不代表高质量，只代表更高的时间分辨率。视频质量受码率、编码格式、拍摄条件等多重因素影响。在同等码率下，高帧率可能因数据量增加而降低每一帧的画质。

**误区三：拍摄时选择高帧率，后期可以随意放慢或加速。**

高帧率素材放慢播放可呈现慢动作效果（如60fps放慢至25fps播放约2.4倍慢动作），但加速播放（如25fps加速至60fps）会产生丢帧、画面跳跃问题。拍摄前应确定目标帧率，高帧率主要用于慢动作，而非随意变速。
:::

## 总结

帧率的选择决定了视频的运动表现风格和观看感受。24fps/25fps适合追求电影感和叙事性的项目，50/60fps适合体育赛事和需要流畅动态的场景，120fps以上则用于慢动作创作。在多机位项目中，所有机位帧率必须统一，这是后期制作的基本前提。
