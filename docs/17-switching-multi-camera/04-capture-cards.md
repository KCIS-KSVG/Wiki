# 17.04 采集卡工作原理

## 核心概念概述

采集卡（Capture Card）是将摄像机、游戏机或其他视频源的信号转换为计算机可识别数字信号的硬件设备。它解决了“摄像机画面如何进入电脑进行直播或录制”这一核心问题，是连接拍摄端与处理端的关键桥梁。

在没有采集卡的情况下，电脑无法直接接收外部视频源的信号。采集卡将相机的 HDMI 或 SDI 输出信号转换为 USB 或 PCIe 接口可传输的数据格式，使 OBS、vMix 等软件能够捕获和处理画面。理解采集卡的工作原理与关键参数，是在直播、录制和多机位制作中正确配置采集设备的基础。

## 一、采集卡的核心功能与原理

### 信号转换过程

采集卡的工作流程可以分为三个核心步骤。第一步是信号接收，通过 HDMI 或 SDI 接口接收视频源输出的数字信号（包括视频和嵌入音频）。第二步是信号转换与压缩，将接收到的视频信号转换为计算机可识别的格式，部分采集卡内置硬件编码芯片以减轻 CPU 负担。第三步是数据传输，通过 USB 或 PCIe 接口将转换后的信号传输至计算机，供直播软件或录制软件使用。

整个过程的关键在于采集卡需要在不引入明显延迟的前提下完成信号的转换与传输。

### 采集卡解决了什么问题

相机、游戏机等设备的 HDMI 或 SDI 输出信号是“纯视频信号”，计算机无法直接读取。采集卡充当翻译官的角色，将这些视频信号“翻译”成计算机可以理解的数据流，使 OBS 等软件能够将其显示为视频源、进行推流或录制。

## 二、采集卡的主要类型

### 内置采集卡

内置采集卡安装于计算机主板的 PCIe 插槽中，直接与主板总线连接。其核心优势是传输带宽极高（PCIe 通道），可实现极低延迟（＜50ms）和无压缩高质量传输，适合高帧率、高分辨率和专业级应用场景。

内置采集卡的安装需要拆开电脑机箱，要求电脑有空闲的 PCIe 插槽，更适合台式机或专业的直播工作站。

### 外置 USB 采集卡

外置采集卡通过 USB 接口连接电脑（USB 3.0 或更高版本），无需拆机即可使用，即插即用。USB 3.0 的带宽足够支持 4K@30fps 或 1080p@60fps 的传输。

外置采集卡是绝大多数直播场景的首选：便携性强，可在不同电脑间快速切换；安装简便，无需任何硬件知识；USB 3.0 的延迟通常可以控制在 60-100ms 内，对于大多数直播场景完全可以接受。

| 对比维度 | 内置采集卡 | 外置 USB 采集卡 |
| :--- | :--- | :--- |
| 安装方式 | PCIe 插槽 | USB 接口 |
| 传输带宽 | 极高 | USB 3.0 足够 |
| 延迟 | 极低（＜50ms） | 低（60-100ms） |
| 便携性 | 不可移动 | 即插即用 |
| 适用设备 | 台式机 | 台式机/笔记本通用 |

## 三、关键参数

### 分辨率与帧率支持

采集卡必须支持输出设备的分辨率和帧率。常见的规格包括 1080p@60fps 和 4K@30fps。确认采集卡支持所拍视频的帧率，避免直播时画面卡顿或丢帧。

### 输入延迟

延迟是采集卡最关键的性能指标之一。专业采集卡的延迟通常在 50ms 以内，USB 3.0 采集卡通常在 60-100ms 之间。对画面实时性要求高的场景（如舞台大屏同步、音乐演出直播），更低的延迟至关重要。

### 环出功能

部分采集卡提供环出（Loop-out / Pass-through）功能——采集信号的同时，将原始信号无延迟输出至另一台显示器或投影设备。当导播需要同时监看原始画面和电脑画面时，环出功能可以避免信号分路导致的延迟。

### UVC 免驱支持

支持 UVC（USB Video Class）标准的采集卡，插入电脑后无需安装驱动即可被 OBS、vMix 等软件识别。在直播场景中，免驱设计大幅简化了现场配置流程，也减少了因驱动不兼容导致的技术问题。

## 四、采集卡的应用场景

**单机位直播：** 一台相机通过 HDMI 连接 USB 采集卡，再接入笔记本电脑。OBS 采集该信号进行推流。适合个人直播、小型会议直播。

**多机位切换直播：** 多台相机分别连接至多路采集卡或切换台，再由主采集卡将切换后的画面送入电脑。适合音乐厅演出、体育赛事等需要实时切换画面的场景。

**相机作为电脑摄像头：** 采集卡使相机可以代替普通网络摄像头，获得更高质量的画面，适合线上会议、网课录制和高质量视频通话。

**游戏直播：** 采集卡连接游戏主机（PS5/Xbox/Switch）与电脑，将游戏画面采集到 OBS 进行直播推流。

## 五、采集卡的选择建议

| 场景 | 推荐类型 | 关键参数 |
| :--- | :--- | :--- |
| 个人直播/小型会议 | USB 3.0 采集卡 | 1080p60，UVC免驱 |
| 多机位切换直播 | USB 3.0 采集卡 | 低延迟，支持环出 |
| 专业高规格制作 | 内置采集卡 | 低延迟，高带宽 |
| 移动直播/笔记本 | USB 3.0 采集卡 | 便携，免驱 |

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：所有 USB 采集卡的延迟都一样。**

USB 2.0 采集卡的延迟通常较高（150ms+），不适合实时直播。USB 3.0 采集卡的延迟通常可控制在 100ms 以内。优先选择 USB 3.0 接口的采集卡。

**误区二：采集卡的分辨率越高越好。**

采集卡的分辨率需匹配相机的输出分辨率和直播平台的最大支持分辨率。若直播平台仅支持 1080p，使用 4K 采集卡不会提升画质，但会占用更多 USB 带宽。

**误区三：采集卡会降低画质。**

高质量采集卡在正确配置下可做到几乎无损传输。画质下降通常源于错误的颜色范围设置（如 0-255 与 16-235 不匹配）或压缩设置不当。选择品牌采集卡并正确配置可避免画质问题。

**误区四：采集卡可以用任意 USB 线连接。**

USB 3.0 采集卡需使用 USB 3.0 数据线才能达到最高性能，使用 USB 2.0 线缆会降速运行，导致分辨率和帧率受限。
:::

## 总结

采集卡是连接相机与电脑的桥梁，将视频信号转换为计算机可识别的数据格式。内置采集卡以高带宽和低延迟见长，适合台式机工作站；外置 USB 采集卡以便携性和即插即用为优势，适合笔记本和移动直播场景。分辨率与帧率支持、延迟、环出功能和 UVC 免驱支持是选购采集卡的核心考量参数。
