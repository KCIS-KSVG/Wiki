# 17.07 校园活动直播搭建实战

## 核心概念概述

校园活动直播是典型的多机位现场制作场景。音乐会、文艺汇演、典礼仪式等活动的不可逆性要求直播系统在活动开始前完成全部搭建和测试，并在活动过程中稳定运行。

本章以校园礼堂演出为例，系统讲解从零搭建完整直播系统的全流程。无论使用硬件导播台还是软件导播方案，核心步骤和注意事项是相通的。

## 一、直播方案的制定

### 需求确认

直播搭建的第一步是确认活动的基本信息。活动类型（音乐会、戏剧、典礼等）、活动时长、流程时间线、是否需要推流至线上平台、是否需要在舞台大屏同步显示，以及是否需要录制存档，都需要在搭建开始前明确。

确认这些信息后，可以确定机位数量、设备配置和系统架构。例如音乐会通常需要3-4个机位（全景+左右侧机位+特写），会议讲座通常需要2-3个机位（全景+发言人特写+观众反应），典礼仪式通常需要3-4个机位（全景+主席台特写+观众反应+游机）。

### 场地勘查

活动前应对场地进行实地勘查，重点确认以下事项：

电源分布方面，确认各机位和导播台附近是否有可用墙插，必要时准备延长线和接线板。网络条件方面，确认推流所需的有线网络接口位置和网络带宽是否满足推流需求。空间限制方面，确认各机位的架设位置是否可行（如观众席通道宽度、视线是否被遮挡）。光线条件方面，确认舞台灯光类型和色温，便于提前设置白平衡。声音环境方面，确认音频采集方案（是否可从调音台获取音频信号，或需独立收音）。

## 二、设备清单与检查

### 视频设备

- 摄像机：根据机位数量准备，建议至少3台（全景机位、侧机位、特写机位）
- 镜头：根据各机位任务配置（广角、标准变焦、长焦）
- 三脚架：每个固定机位配备重型三脚架，确保稳定
- 导播切换设备：ATEM Mini 或搭载 OBS/vMix 的电脑+采集卡
- 监视器：导播台主监视器（建议21英寸以上），各机位可配备机旁监视器
- 信号线缆：HDMI 或 SDI 线缆，长度根据机位到导播台距离确定，预留备用线缆
- 存储卡：各机位备用存储卡，确保容量足够覆盖整场活动
- 电池/电源：各机位备用电池或外接电源方案

### 音频设备

- 音频信号源：调音台输出（最佳方案）或独立麦克风
- 音频线缆：XLR 或 3.5mm 音频线
- 监听耳机：导播台配备，实时监听音频质量

### 网络与推流设备

- 有线网络连接（校园网或专用宽带），优先使用有线网络
- 推流电脑（若使用软件导播方案）
- 备用推流方案（如手机热点，应对主网络故障）

### 通用物资

- 大力胶/布基胶带（固定线缆、标记机位位置、固定音频发射器）
- 接线板/延长线（确保各机位供电）
- 备用电池（各型号相机备用电池）
- 工具包（螺丝刀、扳手等）

## 三、现场搭建流程

### 第一步：导播台架设（提前2-3小时）

选择导播台位置时，应确保导播能清晰看到舞台和所有机位，最好位于观众席后方中央，视线无遮挡。同时需靠近电源和网络接口，方便接线。

架设导播台时，安装主监视器，连接切换设备（ATEM Mini 或电脑+采集卡），连接网络线缆和电源。连接所有输入信号线缆（从各机位延伸过来的 HDMI/SDI 线）至切换设备。通电测试所有设备是否正常启动。

### 第二步：各机位架设（提前2小时）

各机位摄像师领取设备后前往指定位置架设。主机位（全景）架设在观众席正后方中央，使用广角到中焦镜头，确保画面覆盖整个舞台。侧机位左右各一，架设在观众席侧前方或侧后方纵向通道，分别拍摄舞台右侧和左侧。特写机位使用长焦镜头，架设在中后区域，捕捉表演者面部和乐器细节。

各机位架设完成后，连接电源和信号线缆至导播台。使用大力胶在地面固定线缆，防止人员走动时绊倒或拉扯导致信号中断。三脚架锁死各轴向（对固定机位尤为重要），防止意外移动。

### 第三步：音频连接（提前1.5小时）

音频是直播中最容易出问题的环节之一。最佳方案是从调音台获取音频信号，通常使用 XLR 线连接调音台的 AUX 输出或主输出至导播台的音频输入。若调音台输出不可用，可使用现场独立麦克风收音（如机顶枪麦或无线麦克风）。

连接完成后进行音频测试，确认信号电平正常、无爆音或底噪。在 OBS 或导播台中确认音频表显示正常，说话时峰值在 -12dB 到 -6dB 之间，不得顶格。

### 第四步：信号测试（提前1小时）

所有设备架设完成后进行全链路信号测试。逐一确认每个机位的画面是否正常显示在导播监视器上，确认各机位音频信号是否正常传输，确认导播画面输出至推流电脑或直播平台是否正常，确认舞台大屏（若有）画面是否同步且无延迟。

### 第五步：彩排演练（提前30-60分钟）

在正式活动开始前，利用彩排或开场前的时间进行模拟切换演练。导播熟悉活动流程，确认各环节的切换节奏，摄像师确认各机位的拍摄范围和构图，确认各岗位之间的通讯畅通。若发现任何问题，在正式活动开始前解决。

## 四、直播过程中的操作规范

### 导播操作

活动进行中，导播应全程保持专注，根据活动节奏实时切换画面。时刻关注监视器上的各机位画面，预判下一个关键瞬间发生的位置，提前切换到对应机位。保持音频监听，确保音画同步且无异常噪音。

在演出或演讲的间歇（如报幕间隙、节目转换时）进行必要的设备检查，确认录制状态正常、存储卡剩余空间充足。

### 各机位执行

各机位摄像师严格按照分工执行拍摄任务。固定机位摄像师在活动开始后不得移动摄像机、不得变焦、不得关机，直到活动结束或接到明确指令。游机摄像师灵活移动，捕捉花絮和特殊角度，但不得干扰观众和表演者。

若某机位出现存储卡满、电池耗尽等突发情况，应立即通过手势或通讯设备向导播示意，导播协调其他机位保持画面稳定，直到该机位恢复。

## 五、活动结束后的收尾流程

### 设备撤收

活动结束后，各机位摄像师应立即停止录制并保存文件。按顺序撤收设备：先拔掉电源和信号线缆，再拆卸摄像机和三脚架。撕掉地面所有大力胶，清理现场。清点所有设备，确保无遗失（特别注意存储卡、镜头盖、快装板等小件物品）。

### 素材交付

活动结束后尽快将素材拷贝至项目负责人指定的存储位置。文件夹命名格式建议为：`[场次编号]_活动名称_机位编号_拍摄者`，便于后期识别和管理。

### 设备归位

将设备归还至指定存放位置，确认所有设备状态正常。如有设备故障或异常，及时记录并汇报。

## 六、常见问题与应急处理

| 问题 | 应急处理 |
| :--- | :--- |
| 某机位信号中断 | 导播切换至其他机位，摄像师检查线缆连接 |
| 推流网络中断 | 切换至备用网络（如有），或降码率推流 |
| 存储卡满 | 利用节目间隙更换存储卡，或切换至备用录制设备 |
| 音频异常 | 切换至备用音频源（如机顶麦克风） |
| 设备过热 | 暂停使用，移至通风处降温，使用备用设备替代 |

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：设备架设完成后不需要测试，直接等开场即可。**

设备连接可能出现松动、信号格式不匹配等问题。必须提前进行完整的信号测试和彩排演练，确认所有环节正常后再开始正式活动。

**误区二：线缆只要连接上就行，不需要固定。**

活动现场人员走动频繁，未固定的线缆容易被踢松或绊倒人。所有线缆必须使用大力胶固定在地面，或沿墙边、通道边缘走线。

**误区三：推流网络使用 Wi-Fi 即可。**

Wi-Fi 信号易受干扰，在观众密集的场地中可能不稳定。直播推流应优先使用有线网络连接，确保带宽和稳定性。若必须使用 Wi-Fi，建议使用 5GHz 频段并确保信号强度充足。
:::

## 总结

校园活动直播搭建是一项系统工程，涉及方案设计、设备准备、现场搭建、信号测试、彩排演练和正式直播等多个环节。提前勘查场地、制定详细方案、准备备用设备和线缆、进行完整的信号测试和彩排，是保障直播顺利进行的关键。在直播过程中保持专注、灵活应对突发状况，在活动结束后规范撤收和交付素材，构成了一次完整的校园活动直播项目执行闭环。
