# 23.03 模特肖像授权 Model Release

## 核心概念概述

模特肖像授权书（Model Release）是一份法律文件，被摄者通过签署该文件，授权摄影师将其肖像用于商业用途[reference:0]。无论你是为商业客户拍摄、建立作品集，还是销售图库摄影，取得签署完成的授权文件都非常重要[reference:1]。它既是摄影师合法使用他人肖像的法律依据，也是规避肖像权纠纷的核心手段[reference:2]。

## 一、肖像权的法律基础

### 民法典的核心规定

《中华人民共和国民法典》第四编“人格权”第四章对肖像权作出了系统规定[reference:3]。根据民法典第一千零一十八条，自然人享有肖像权，有权依法制作、使用、公开或者许可他人使用自己的肖像[reference:4][reference:5]。肖像是通过影像、雕塑、绘画等方式在一定载体上所反映的特定自然人可以被识别的外部形象[reference:6][reference:7]。

这意味着，在摄影中，只要照片能够使他人识别出特定的自然人，就涉及肖像权的保护问题。

### 肖像权保护的核心规则

民法典第一千零一十九条规定：“任何组织或者个人不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权。未经肖像权人同意，不得制作、使用、公开肖像权人的肖像，但是法律另有规定的除外。”[reference:8]

这一条有三个关键要点：

**“制作”即可能构成侵权**：未经肖像权人允许，擅自拍摄他人肖像的行为，涉嫌侵害他人肖像权[reference:9]。只要用相机或手机拍到对方，属于法律上的制作行为，如果未得到对方允许，就可能构成侵权[reference:10]。

**删除“以营利为目的”要件**：民法典对肖像权保护的一个重要修改，是删除了此前《民法通则》第一百条中“以营利为目的”的构成要件[reference:11]。这意味着，即使不用于商业目的，未经同意制作、使用或公开他人肖像，仍可能构成侵权。

**未经同意的使用是核心红线**：未经肖像权人同意，不得制作、使用、公开肖像权人的肖像[reference:12][reference:13]。肖像作品权利人（即摄影师）未经肖像权人同意，也不得以发表、复制、发行、出租、展览等方式使用或公开肖像权人的肖像[reference:14][reference:15]。

### 肖像权的合理使用

民法典第一千零二十条规定了可以不经肖像权人同意的五种情形[reference:16][reference:17]：

1. 为个人学习、艺术欣赏、课堂教学或者科学研究，在必要范围内使用肖像权人已经公开的肖像
2. 为实施新闻报道，不可避免地制作、使用、公开肖像权人的肖像
3. 为依法履行职责，国家机关在必要范围内制作、使用、公开肖像权人的肖像
4. 为展示特定公共环境，不可避免地制作、使用、公开肖像权人的肖像
5. 为维护公共利益或者肖像权人合法权益的其他行为

在校园活动拍摄中，若照片仅用于内部存档或新闻报道，可能适用合理使用规则；但若用于学校官网、招生宣传册、社交媒体推广等商业性或宣传性用途，则应取得被摄者的书面授权。

## 二、何时需要模特肖像授权书

**商业用途必须签署**：只要计划将照片用于商业用途——广告投放、营销宣传、产品包装、图库销售——就需要模特肖像授权书[reference:18]。即使被摄者是亲友，只要涉及商业使用，也应当取得书面同意[reference:19]。没有签署授权书，可能面临法律责任，且通常无法合法销售或授权影像作商业用途[reference:20]。

**编辑用途通常不需要**：多数情况下，编辑用途（如新闻报道、具有公共利益的纪实内容）通常不一定需要模特肖像授权书[reference:21]。但编辑与商业用途的界限有时较为复杂，如果不确定，建议先取得授权以降低法律风险[reference:22]。

**建议“能签尽签”**：即使拍摄项目当前不涉及商业用途，也难以预判照片未来是否会被用于商业场景。签署授权书是成本最低的风险防范措施。

## 三、肖像授权书的核心内容

一份完整的照片肖像授权书通常应包含以下核心内容[reference:23]：

**被摄者信息**：姓名、联系方式、身份证号码（可选），用于明确授权主体。

**摄影师/使用方信息**：姓名、联系方式，用于明确授权对象。

**拍摄内容描述**：拍摄的日期、地点、内容简介。建议把肖像摄影作品小样附在协议后[reference:24]。

**授权使用范围**：使用用途（商业/非商业/编辑）、使用媒介（网络、印刷、电视等）、地域范围、使用期限[reference:25]。

**报酬条款（如适用）**：是否支付报酬及支付方式[reference:26]。

**对作品的修改权**：是否允许对原始作品进行改动、裁剪或加工[reference:27]。

**责任免除条款**：被摄者免除摄影师因授权使用而产生的相关法律责任[reference:28]。

**签名与日期**：双方签字并注明日期，确保法律效力[reference:29]。

## 五、商业使用中的双重授权问题

在以营利为目的使用他人肖像摄影作品时，需要注意一个容易被忽视的问题：**双重授权**。

摄影作品中同时存在两种权利——**著作权**（属于摄影师）和**肖像权**（属于被摄者）[reference:38][reference:39]。当第三方想要商业使用一张人物照片时，需要同时获得：

1. **摄影师的著作权授权**：授权使用该摄影作品
2. **被摄者的肖像权授权**：授权使用其肖像

仅有摄影师的授权而没有被摄者的肖像授权，仍可能构成肖像权侵权[reference:40]。因此，在拍摄涉及人物的商业项目时，摄影师不仅应为自己保留著作权，还应确保获得了被摄者的肖像授权，以便在必要时能够向第三方提供完整的授权链。

## 六、未成年人肖像授权

拍摄未成年人时，肖像授权有特殊要求。民法典规定，未成年人的肖像权由其监护人代为行使。具体操作要点如下：

- 授权书必须由**监护人**（父母或其他法定监护人）签字确认[reference:41]
- 监护人应在签字栏中注明与被摄者的关系
- 建议同时在授权书中附上监护人的身份信息
- 如监护人同意，应代表被摄者签署授权书[reference:42]

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：口头同意就足够了，不需要书面授权。**

口头同意通常不足以作为商业照片使用权的法律依据。需要书面且签署完成的模特肖像授权书，才能在面临争议时提供有效的法律保护[reference:43]。

**误区二：只要不用于商业用途，拍摄任何人都不需要授权。**

民法典已删除“以营利为目的”的构成要件[reference:44]。未经肖像权人同意，即使是个人欣赏性质的拍摄（“制作”行为），也可能构成侵权[reference:45]。

**误区三：拍摄公开场合的人物不需要肖像授权。**

在公共场所拍摄并不意味着可以随意使用他人肖像。民法典第一千零一十九条并未将“公共场所”列为合理使用的例外情形。未经同意在公共场所拍摄并公开他人肖像，仍可能构成侵权。只有在符合第一千零二十条规定的五种合理使用情形时，才可不经同意使用。

**误区四：有了肖像授权书就可以随意使用照片。**

肖像授权书明确约定了使用的范围、期限和方式。超出授权范围的使用（如将授权用于网络展示的照片用于印刷广告）可能构成违约或侵权。

**误区五：只要付了拍摄费用，肖像权就自动归属于摄影师。**

支付拍摄费用与肖像授权是两个独立的法律关系。拍摄费用可能仅覆盖拍摄服务本身，而不包含肖像的商业使用权。如需将照片用于商业用途，仍需另行取得被摄者的书面肖像授权。
:::

## 总结

模特肖像授权书是摄影师合法使用他人肖像的法律基础。民法典明确规定，未经肖像权人同意，不得制作、使用、公开其肖像，且已删除“以营利为目的”的构成要件。在商业拍摄、图库销售、广告宣传等场景中，取得书面的肖像授权书是必需的。授权书应包含被摄者信息、使用范围、使用期限、报酬条款和双方签名等核心内容。拍摄未成年人时需由监护人签字确认。在人物摄影的商业使用中，还需注意著作权与肖像权的双重授权问题。
