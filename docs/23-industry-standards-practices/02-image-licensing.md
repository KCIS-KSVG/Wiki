# 23.02 图片授权 License 规则

## 核心概念概述

图片授权（License）是指著作权人（摄影师）许可他人在约定的范围、期限和方式内使用其摄影作品的行为。授权不等于转让著作权——摄影师仍然保留作品的著作权，只是允许被授权方在特定条件下使用作品。

在实际工作中，无论是将照片授权给媒体使用、上传至图库销售，还是与客户签订商业拍摄合同，都涉及授权规则的适用。理解授权的基本类型、使用范围界定和合同要点，是保障摄影师权益、避免授权纠纷的基础。

## 一、著作权许可的基本类型

根据《中华人民共和国著作权法》，著作权许可使用合同应当明确许可使用的权利种类、是否专有使用、地域范围和期限等要素[reference:0]。从许可的独占程度来看，著作权许可可分为三种基本类型[reference:1]。

### 普通许可（非专有许可）

普通许可是指许可方（摄影师）允许被许可方在规定范围内使用作品，同时**保留自己在该范围内使用作品**以及**许可其他人使用该作品**的权利[reference:2][reference:3]。

这是最常见的授权方式。摄影师将照片授权给一家媒体使用，同时仍可将同一张照片授权给其他媒体或用于其他用途。被许可方不能阻止摄影师将作品授权给他人。

在实际操作中，普通许可是绝大多数图片授权的基础模式。一张照片可以被多家媒体、多个项目同时使用，摄影师可以通过多次授权获得持续收益[reference:4]。

### 排他许可

排他许可是指许可方允许被许可方在规定范围内使用作品，同时**保留自己在该范围内使用作品的权利**，但**不得再许可其他人使用**该作品[reference:5]。

在排他许可下，被许可方获得了一定程度的市场独占性——在同一范围内，只有被许可方和摄影师本人可以使用该作品，第三方无权使用。排他许可通常适用于需要一定独占性但摄影师仍希望保留自用权利的场景。

### 独占许可

独占许可是指许可方允许被许可方在规定范围内使用作品，同时**在许可期内自己也无权行使相关权利**，更**不得另行许可其他人使用**该作品[reference:6]。

在独占许可下，在合同约定的范围内和期限内，**只有被许可方可以使用该作品**。摄影师本人也不能使用该作品[reference:7]。独占许可是限制最严格、授权费用最高的许可类型，通常适用于品牌广告、大型商业项目等需要完全独占视觉素材的场景。

在独占许可下，如果摄影师违反合同约定自行使用或授权他人使用该作品，不但构成合同违约，也可能涉嫌著作权侵权[reference:8]。

### 三种许可类型的核心区别

| 许可类型 | 摄影师能否自用 | 摄影师能否再授权他人 | 被许可方享有的权利 |
| :--- | :--- | :--- | :--- |
| 普通许可 | ✅ 可以 | ✅ 可以 | 在约定范围内使用 |
| 排他许可 | ✅ 可以 | ❌ 不可以 | 独占使用权（摄影师除外） |
| 独占许可 | ❌ 不可以 | ❌ 不可以 | 完全独占使用权 |

## 二、图库授权模式：RF与RM

在图库摄影领域，授权模式主要分为两种国际通用的类型：RF（免版税）授权和RM（版权管理）授权[reference:9][reference:10]。两者的核心区别在于定价逻辑和使用限制[reference:11]。

### RF授权（Royalty-Free，免版税）

RF授权是“免版税”授权，而非“免费”授权[reference:12]。用户一次性支付费用后，可在广泛的用途中多次使用该图片，通常不受时间、地域和发行数量的严格限制[reference:13][reference:14]。

RF授权的核心特点包括：一次性付费，不限使用次数[reference:15]；使用范围广泛，可用于网站、社交媒体、广告等多种场景[reference:16]；无需为每次使用单独支付版税[reference:17]；**非独占性**——同一张图片可被多家公司同时使用[reference:18]。

RF授权是目前图库行业的主流模式，尤其适合需要大量使用图片但预算有限的场景[reference:19]。其优势在于灵活高效，团队无需反复协商授权条款即可快速推进项目[reference:20]。

### RM授权（Rights-Managed，版权管理）

RM授权是基于特定用途的授权模式。授权费用和条款根据**具体使用方式**确定[reference:21]，定价因素包括使用期限、地域范围、发行数量、媒体类型、行业类别和是否要求独占等[reference:22]。

RM授权的核心特点是按“用途”定价——使用方式越广泛、期限越长、受众越多，费用越高[reference:23][reference:24]。授权范围明确，所有使用均有记录[reference:25]。可协商独占或半独占使用[reference:26][reference:27]。合同条款复杂，需要精确约定使用细节。

RM授权的费用通常高于RF授权[reference:28][reference:29]。其核心价值在于**控制力和排他性**——品牌可以防止竞争对手在同一广告 campaign 中使用相同的视觉素材[reference:30]。

### RF与RM的选择

| 对比维度 | RF授权 | RM授权 |
| :--- | :--- | :--- |
| 定价依据 | 图片尺寸/单位 | 具体使用方式 |
| 使用限制 | 较少 | 严格（期限/地域/用途） |
| 独占性 | 无 | 可协商 |
| 灵活性 | 高 | 低 |
| 费用 | 较低 | 较高 |
| 适用场景 | 高频使用、预算有限 | 品牌广告、需独占 |

在选择授权模式时，应考虑以下因素：如果项目需要快速推进、内容将被高频复用、预算有限且不要求独占性，RF授权更为合适[reference:31]。如果项目对原创性要求极高、广告曝光量大、竞争对手使用相同素材会造成问题、需要精确的授权条款，RM授权更为合适[reference:32]。

## 三、使用范围的界定

在授权合同中，使用范围的界定是核心内容之一。明确的使用范围可以避免双方对授权边界的争议。

### 商业用途 vs 非商业用途

商业用途是指以营利为目的使用摄影作品，包括广告、产品包装、商品宣传等[reference:33]。非商业用途包括作品的发表、参赛、展示及教学等[reference:34]。两者的界限在于是否有营利的行为或目的[reference:35]。

需要注意的是，**非商业用途不等于可以免费使用**。即使是非商业性的公开传播（如在个人博客、公众号中使用他人照片），同样需要获得著作权人的许可[reference:36]。

### 编辑用途

编辑用途通常限定于新闻传播、媒体报道等场景，禁止转授权和广告等商业性使用[reference:37]。获得商业用途授权的图片比获得报道用途授权的图片有更多限制，因为商业内容用于广告和促销[reference:38]。

### 使用范围的具体条款

在授权合同中，使用范围应具体明确。著作权许可合同通常需要约定的内容包括：许可使用的权利种类（如复制权、展览权、信息网络传播权等）；许可使用的是专有使用权还是非专有使用权[reference:39]；许可使用的地域范围和期限[reference:40]；付酬标准和办法[reference:41]；违约责任等[reference:42][reference:43]。

## 四、授权合同的核心条款

一份规范的摄影作品授权合同通常应包含以下核心条款[reference:44]：

**许可性质**：明确授权的类型（普通许可、排他许可还是独占许可），被许可方是否享有转授权的权利[reference:45]。

**使用方式和期限**：约定作品的具体使用方式（展览、复制、网络传播等），以及授权的起止日期[reference:46]。

**授权地域范围**：明确被许可方在哪些地域范围内可以使用作品。

**作品清单**：详细列出被授权的具体作品名称和数量[reference:47]。

**使用费用**：约定授权费用金额和支付方式[reference:48]。

**权利保证**：许可方保证对作品享有完整、独立的著作权，未侵犯他人权利[reference:49]。

**违约责任**：明确违反各项约定的赔偿标准[reference:50]。

**争议解决**：约定纠纷的解决方式和管辖法院[reference:51]。

## 五、授权中的常见问题

### 委托作品的著作权归属

委托他人拍摄的照片，著作权的归属由委托人和受托人通过合同约定。合同未明确约定或没有订立合同的，著作权属于受托人（摄影师）[reference:52]。著作权属于受托人的，委托人有权在约定的使用范围内使用该作品；没有约定使用范围的，有权在委托创作的特定目的范围内免费使用该作品[reference:53]。

### 转授权的限制

在普通许可中，被许可方通常不得转授权他人或超出授权范围使用作品[reference:54]。如需转授权，应在合同中明确约定。

### 合理使用与法定许可

著作权法规定了合理使用的若干情形，如为个人学习、研究、欣赏，为介绍、评论某一作品，为报道新闻等[reference:55]。但合理使用有严格的适用范围，并非所有“非商业用途”都属于合理使用[reference:56]。著作权属于著作权人的专有权利，只能由著作权人授权使用。如果没有法定许可、合理使用等特殊事由，未经授权使用的行为可认定为侵权行为[reference:57]。

### 授权链条的完整性

在多层授权的场景中（如图库代理），授权链条的完整性至关重要。每一级授权都需要有合法的权利来源[reference:58]。如果授权链条中存在断裂或瑕疵，下游使用者可能面临侵权风险[reference:59]。

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：购买了图片的使用权就拥有了图片的著作权。**

购买使用授权不等于获得著作权。著作权仍属于摄影师，购买者仅在授权范围内使用作品。超出授权范围的使用（如将授权用于网络展示的照片用于印刷品）可能构成侵权。

**误区二：RF授权等于“免费使用”。**

RF（Royalty-Free）是“免版税”而非“免费”。用户仍需支付一次性授权费用，才能获得在约定范围内使用图片的权利。

**误区三：口头授权和书面授权效力相同。**

口头授权虽然在法律上可能有效，但在发生纠纷时难以举证。建议所有授权均以书面合同形式确认，明确约定权利种类、使用范围、期限和费用等核心条款。

**误区四：非商业用途不需要获得授权。**

非商业用途不等于合理使用。除法律明确规定的合理使用情形外，任何对他人摄影作品的使用都需要获得著作权人的许可[reference:60]。
:::

## 总结

图片授权是摄影作品合法传播和商业化的基础。著作权许可分为普通许可、排他许可和独占许可三种类型，独占程度逐级递增。在图库领域，RF授权以灵活性和效率见长，RM授权以控制力和排他性为核心优势。授权合同应明确约定许可性质、使用方式、地域范围、期限、费用和违约责任等核心条款。理解授权规则，在授权前明确边界、在授权时签订合同、在授权后监督执行，是规范进行作品授权的基本路径。
