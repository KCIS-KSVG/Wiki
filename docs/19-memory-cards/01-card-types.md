# 19.01 存储卡类型总览

## 核心概念概述

存储卡是数码相机记录影像数据的核心介质。不同类型的存储卡在物理尺寸、传输速度、容量上限和适用设备上存在显著差异。目前摄影领域主流的存储卡类型包括 SD 卡、microSD 卡、CFexpress 卡、XQD 卡以及传统的 CF 卡。[reference:0]

理解各类存储卡的特点和适用场景，是在选购存储卡时做出正确决策的前提。不同类型的相机对存储卡的支持各不相同——入门级相机通常使用 SD 卡，高端机型可能同时支持 SD 卡和 CFexpress 卡，部分旗舰机型则仅支持高速卡槽。[reference:1]

## 一、SD 卡：最通用的标准

### 核心定位

SD 卡（Secure Digital Card）是目前数码相机中最常见、应用最广泛的存储卡类型，外形尺寸为 32mm × 24mm × 2.1mm。[reference:2]市面上绝大多数单反相机、微单相机都支持使用 SD 卡，只有少数高端相机设备不支持。[reference:3]

### 容量分级

SD 卡按容量分为四个标准等级。[reference:4]

SD 标准对应 2GB 及以下容量，目前已基本淘汰。SDHC（Secure Digital High Capacity）标准对应超过 2GB、最高 32GB 的容量。[reference:5]SDXC（Secure Digital eXtended Capacity）标准对应超过 32GB、最高 2TB 的容量，是当前市场的主流。[reference:6]SDUC（Secure Digital Ultra Capacity）标准对应超过 2TB、最高 128TB 的容量，是新推出的标准，预计将逐步进入市场。[reference:7][reference:8]

### 速度等级

SD 卡还根据速度等级进一步细分，包括速度等级（Class）、UHS 速度等级（U1/U3）和视频速度等级（V30/V60/V90），具体内容将在后续章节详细讲解。

### 主要优势与局限

SD 卡的优势在于兼容性极广——几乎所有相机品牌和型号都支持 SD 卡；价格相对亲民，从入门级到专业级均有丰富的选择；读写速度可满足大部分静态照片和 4K 视频拍摄需求。其局限在于速度上限不及 CFexpress 等专业卡型，在需要持续高速写入 8K RAW 视频或极限连拍的场景中可能成为瓶颈。[reference:9]

## 二、microSD 卡：小尺寸的便携方案

### 核心定位

microSD 卡原名 Trans-flash Card（TF 卡），由闪迪公司发明，后被 SD 协会采纳并更名为 microSD 卡。[reference:10][reference:11]其外形尺寸仅为 15mm × 11mm × 1mm，约为标准 SD 卡的四分之一。[reference:12][reference:13]

### 主要应用场景

microSD 卡广泛用于智能手机、平板电脑、运动相机（如 GoPro、DJI Action）、无人机、安防摄像头、行车记录仪等对体积有严格要求的便携设备中。[reference:14][reference:15]

### 与 SD 卡的关系

microSD 卡与 SD 卡遵循相同的容量标准——microSD、microSDHC、microSDXC、microSDUC 的容量分级与 SD 卡完全一致。[reference:16]microSD 卡通常附带 SD 卡适配器，插入适配器后可在标准 SD 卡槽中使用。[reference:17]但需注意，部分相机对 microSD 卡的写入速度要求较高，使用适配器时可能影响性能表现。

## 三、CFexpress 卡：新一代高速标准

### 核心定位

CFexpress 卡是 CompactFlash 协会于 2016 年发布的新一代高速存储卡标准。它基于 PCIe 接口和 NVMe 协议，与计算机中的高性能固态硬盘（SSD）采用相同的底层技术。[reference:19]CFexpress 卡是目前摄影领域速度最快的存储卡类型，专为 8K RAW 视频录制和极限高速连拍而设计。[reference:20]

### 三种形态

CFexpress 标准目前定义了三种物理形态。[reference:21]

Type A 是最小的形态，尺寸为 20mm × 28mm × 2.8mm，比标准 SD 卡略小。[reference:22]它采用单条 PCIe 通道，理论最大速度为 1000MB/s。[reference:23][reference:24]

Type B 的尺寸为 38.5mm × 29.8mm × 3.8mm，与 XQD 卡完全相同。[reference:25][reference:26]它采用两条 PCIe 通道，理论最大速度为 2000MB/s。[reference:27][reference:28]Type B 是目前专业相机中最常用的 CFexpress 卡型。

Type C 是最大的形态，尺寸为 54mm × 74mm × 4.8mm，采用四条 PCIe 通道，理论最大速度可达 4000MB/s。[reference:29]Type C 主要面向工业应用，不用于消费级或专业相机。[reference:30]

| CFexpress 类型 | 尺寸 | PCIe 通道数 | 理论最大速度 |
| :--- | :--- | :--- | :--- |
| Type A | 20×28×2.8mm | 1 条 | 1000 MB/s |
| Type B | 38.5×29.8×3.8mm | 2 条 | 2000 MB/s |
| Type C | 54×74×4.8mm | 4 条 | 4000 MB/s |

### 版本演进

CFexpress 已从 2.0 版本演进至 4.0 版本。CFexpress 2.0 采用 PCIe Gen3 技术。[reference:31]CFexpress 4.0 采用 PCIe Gen4 技术，理论带宽是 Gen3 的两倍——Type A 可达 2000MB/s，Type B 可达 4000MB/s。[reference:32]CFexpress 4.0 向下兼容 CFexpress 2.0 设备。[reference:33]

## 四、XQD 卡：CFexpress 的前身

### 核心定位

XQD 卡是索尼、闪迪、尼康三方于 2010 年联合推出的高速存储卡标准。[reference:34]其尺寸为 38.5mm × 29.8mm × 3.8mm。[reference:35]XQD 卡基于 PCIe 接口，读写速度远超同期 SD 卡，可达 400MB/s 以上。[reference:36][reference:37]

### 适用机型

XQD 卡主要应用于尼康的专业相机（如 D4、D5、D850、Z 系列）及索尼的部分专业摄录机。[reference:38][reference:39]由于其价格较高，XQD 卡仅在少数高端机型中采用。[reference:40]

### 与 CFexpress 的关系

XQD 卡与 CFexpress Type B 卡在物理尺寸和接口上完全一致。[reference:41]部分尼康相机（如 Z 系列）的 XQD 卡槽可通过固件更新兼容 CFexpress Type B 卡。[reference:42]CFexpress 可视为 XQD 的技术升级版——性能更强，且属于开放行业标准（XQD 为索尼主导的标准）。[reference:43]

### 现状

随着 CFexpress 标准的普及，XQD 卡正逐步被 CFexpress Type B 取代。[reference:44]新型号的专业相机多直接采用 CFexpress Type B 卡槽。仍在使用的 XQD 卡用户可在兼容机型上继续使用。

## 五、CF 卡：曾经的行业标准

### 核心定位

CF 卡（CompactFlash）是闪迪于 1994 年推出的早期存储卡标准。[reference:45][reference:46]其尺寸为 43mm × 36mm × 3.3mm。[reference:47]CF 卡采用 50 针接口，以稳定性和可靠性著称，曾是专业单反相机的标配存储介质。[reference:48]

### 现状

随着 SD 卡性能的提升和 CFexpress 等新标准的出现，CF 卡在速度和容量上已无明显优势。[reference:49]目前 CF 卡主要仍在使用老旧机型的摄影师群体中使用，新发布的相机已不再配备 CF 卡槽。[reference:50]

## 六、各类存储卡对比总览

| 存储卡类型 | 外形尺寸 | 主要接口 | 典型速度 | 适用设备 |
| :--- | :--- | :--- | :--- | :--- |
| SD 卡 | 32×24×2.1mm | UHS-I/II | 最高 312MB/s | 绝大多数相机 |
| microSD 卡 | 15×11×1mm | UHS-I/II | 同 SD 卡 | 运动相机、无人机、手机 |
| CFexpress Type A | 20×28×2.8mm | PCIe 3.0×1 | 最高 1000MB/s | 索尼高端机型 |
| CFexpress Type B | 38.5×29.8×3.8mm | PCIe 3.0×2 | 最高 2000MB/s | 佳能、尼康、松下旗舰机型 |
| XQD 卡 | 38.5×29.8×3.8mm | PCIe | 最高 440MB/s | 尼康、索尼部分专业机型 |
| CF 卡 | 43×36×3.3mm | PCMCIA-ATA | 最高 160MB/s | 老旧专业单反 |

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：所有相机都兼容所有类型的存储卡。**

不同相机支持的存储卡类型各不相同。购买前务必查阅相机说明书或官网规格，确认支持的卡型。部分相机支持多卡槽混合使用，但各卡槽支持的类型可能不同。

**误区二：microSD 卡加装适配器后性能与 SD 卡完全一致。**

虽然 microSD 卡配合适配器可在 SD 卡槽中使用，但部分适配器的传输性能可能不及原生 SD 卡。在需要高速连拍或高码流视频录制的场景中，建议优先使用原生 SD 卡。

**误区三：CFexpress Type B 卡与 XQD 卡完全通用。**

虽然两者物理尺寸和接口相同，但并非所有 XQD 卡槽都兼容 CFexpress Type B 卡。需确认相机是否已更新固件以支持 CFexpress，且部分早期 XQD 卡槽可能仅兼容 XQD 卡。[reference:51]
:::

## 总结

摄影存储卡主要分为 SD 卡、microSD 卡、CFexpress 卡、XQD 卡和 CF 卡五大类型。SD 卡以通用性和性价比成为绝大多数相机的标配；microSD 卡以小巧体积适配运动相机和无人机等便携设备；CFexpress 卡以 PCIe 接口和 NVMe 协议提供极致速度，是 8K 视频和极限连拍的专业之选；XQD 卡作为 CFexpress 的前身，仍在部分老款专业相机中服役；CF 卡则已基本退出历史舞台。理解各类存储卡的特点和适用场景，是正确配置相机存储系统的第一步。
