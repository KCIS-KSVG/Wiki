# 19.06 TF 卡 / MicroSD 区别

## 核心概念概述

MicroSD 卡是目前最广泛使用的小尺寸存储卡标准，广泛应用于运动相机、无人机、智能手机、平板电脑和安防摄像头等设备中。

它最初由闪迪公司于 2004 年推出，原名为 **TransFlash（TF 卡）**。2005 年，SD 协会正式将其纳入 SD 标准体系，更名为 **MicroSD**，使其与 SD 卡标准完全兼容。如今，TF 卡和 MicroSD 卡指代的是同一种产品，只是不同时期、不同地区用户的习惯称呼差异。

理解 MicroSD 与标准 SD 卡的关系、速度等级的对应以及适配器的使用方式，是在选购和配置便携设备存储方案时的重要知识。

## 一、TF 卡与 MicroSD 的名称由来

### TransFlash（TF 卡）

2004 年，闪迪公司（SanDisk）联合摩托罗拉推出了一种全新的超小型存储卡，命名为 **TransFlash**。其尺寸仅为 15mm × 11mm × 1mm，约为当时主流 SD 卡的四分之一，主要面向功能手机和便携数码设备。

### MicroSD 名称的确定

2005 年，SD 协会（SDA）正式将 TransFlash 纳入 SD 标准体系，并将其更名为 **MicroSD**，使其与 SD 卡标准在电气接口和协议上完全统一。

如今，“TF 卡”和“MicroSD”在市场上指代的是同一种产品，只是称呼不同。在中国大陆，“TF 卡”的称呼依然广泛使用。

## 二、MicroSD 与标准 SD 卡的关系

### 容量的对应关系

MicroSD 卡的容量分级与标准 SD 卡完全一致。

| 标准 | 容量范围 | 文件系统 |
| :--- | :--- | :--- |
| MicroSD | ≤ 2GB | FAT12/FAT16 |
| MicroSDHC | 4GB – 32GB | FAT32 |
| MicroSDXC | 64GB – 2TB | exFAT |
| MicroSDUC | 2TB – 128TB | exFAT |

### 速度等级的对应关系

MicroSD 卡的速度等级标识也与标准 SD 卡完全相同，包括 Speed Class（Class 2/4/6/10）、UHS Speed Class（U1/U3）和 Video Speed Class（V10/V30/V60/V90）。

| 速度等级 | 最低写入速度 | 适用场景 |
| :--- | :--- | :--- |
| Class 2/4/6 | 2/4/6 MB/s | 基础照片、标清视频 |
| Class 10 / U1 | 10 MB/s | 全高清视频、常规照片 |
| U3 / V30 | 30 MB/s | 4K 视频 |
| V60 | 60 MB/s | 高码流 4K 视频 |
| V90 | 90 MB/s | 8K 视频、高码流录制 |

## 三、MicroSD 适配器（卡套）的使用

MicroSD 卡通常附带一个 SD 卡适配器（俗称卡套），可将 MicroSD 卡插入标准 SD 卡槽中使用。

### 工作原理

适配器内部没有电子芯片，仅通过物理引脚将 MicroSD 卡的金手指与 SD 卡槽的触点连接。MicroSD 卡的电气性能和速度等级决定了适配器使用时的速度上限。

### 使用注意事项

在要求高速写入的场景（如 4K 视频录制、高码流连拍）中，MicroSD 卡配合适配器使用可能存在性能瓶颈。适配器的物理连接可靠性不如原生 SD 卡，在震动较大的环境中可能出现接触不良。

部分相机可能无法识别通过适配器使用的 MicroSD 卡，尤其是老旧设备或对存储卡规格有严格要求的专业机型。

### 建议

在主力相机（单反、微单）中，建议优先使用原生 SD 卡而非 MicroSD + 适配器。在运动相机、无人机等原生采用 MicroSD 卡槽的设备中，可直接使用 MicroSD 卡，无需适配器。

## 四、MicroSD 卡的典型应用设备

| 设备类型 | 典型用途 | 速度要求 |
| :--- | :--- | :--- |
| 运动相机（GoPro、DJI Action） | 4K 视频录制 | V30 / V60 |
| 无人机（DJI 系列） | 航拍视频、照片 | V30 / V60 |
| 行车记录仪 | 连续循环录制 | V30 |
| 安防摄像头 | 持续监控录制 | V10 / V30 |
| 智能手机/平板电脑 | 照片、音乐、应用扩展 | U1 / U3 |
| 游戏机（Nintendo Switch） | 游戏存储 | U3 |

## 五、选购建议

### 确认设备兼容性

在购买 MicroSD 卡前，务必确认设备支持的最高容量标准。老旧设备可能仅支持 MicroSDHC（32GB 以内），不支持 MicroSDXC（64GB 及以上）。无人机和运动相机等设备通常支持 MicroSDXC。

### 根据拍摄场景选择速度等级

| 场景 | 推荐速度等级 | 说明 |
| :--- | :--- | :--- |
| 航拍 4K 视频 | V30 / U3 | 大疆无人机等设备的标准需求 |
| 运动相机 4K/5.3K | V30 / V60 | 高码流录制需较高持续写入速度 |
| 行车记录仪 | V30 / U3 | 循环录制，稳定性优先 |
| 日常照片/手机扩展 | U1 / Class 10 | 满足基础需求即可 |

### 注意耐用性

运动相机、行车记录仪和安防摄像头等设备通常需要 7×24 小时持续写入，对存储卡的耐用性要求较高。在这些场景中，建议选择标明“高耐用性”或“监控专用”的 MicroSD 卡，这类产品通常采用更高品质的闪存颗粒，具备更长的写入寿命。

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：TF 卡和 MicroSD 卡是两种不同的存储卡。**

TF 卡是 MicroSD 卡的旧称。两者指代的是完全相同的产品。2005 年 SD 协会将 TransFlash（TF）纳入 SD 标准并更名为 MicroSD 后，两者在技术规格和物理尺寸上完全一致。

**误区二：MicroSD 卡加装适配器后性能与原生 SD 卡完全一致。**

虽然适配器仅负责物理引脚连接，不涉及信号处理，但适配器的接触质量和连接稳定性可能影响实际读写性能。在需要高速、稳定写入的专业拍摄场景中，建议使用原生 SD 卡。

**误区三：任何 MicroSD 卡都适合用于运动相机和无人机。**

运动相机和无人机通常需要较高的持续写入速度。使用低速 MicroSD 卡（如 Class 4 或 Class 6）可能导致录制中断或画面卡顿。务必根据设备说明书的要求选择对应的速度等级。

**误区四：MicroSDXC 卡可以在任何设备上使用。**

MicroSDXC（64GB 以上）采用 exFAT 文件系统，老旧设备可能不支持。在购买前需确认设备是否明确标注支持 SDXC 标准。
:::

## 总结

MicroSD（原名 TF 卡）以 15×11×1mm 的超小尺寸，成为运动相机、无人机、智能手机等便携设备的理想存储方案。它与标准 SD 卡共享相同的容量分级（SDHC/SDXC/SDUC）和速度等级（Class/UHS/V 系列）。在适配器辅助下，MicroSD 卡可在标准 SD 卡槽中使用，但在专业拍摄场景中建议优先使用原生 SD 卡以确保稳定性和性能。根据设备的写入速度要求和耐用性需求选择合适的 MicroSD 卡，是保障拍摄连续性和数据安全的关键。
