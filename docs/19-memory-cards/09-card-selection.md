# 19.09 摄影存储卡选购指南

## 核心概念概述

存储卡的选购不仅仅是“买一张容量够大的卡”。它需要在相机支持的卡型、拍摄场景的速度需求、容量规划与预算之间做出综合权衡。一张选择不当的存储卡，可能导致连拍卡顿、视频录制中断，甚至素材丢失。

本章将按照不同的设备类型和拍摄场景，系统讲解存储卡的选择策略，帮助读者在复杂的规格参数中做出明智的采购决策。

## 一、选择存储卡的四步流程

选购存储卡的基本逻辑可以概括为四个步骤：

### 第一步：确认相机支持的卡型

在考虑任何速度或容量之前，首先确认相机支持哪些类型的存储卡。查阅相机说明书或官网规格中的“存储介质”一项，确认相机支持 SD（SDHC/SDXC）还是 CFexpress（Type A/Type B）或 XQD。

不同相机可能配备不同类型的卡槽。有些相机配备双卡槽但规格不同，需确认每个卡槽支持的卡型。部分机型需要通过固件更新才能支持新卡型。

### 第二步：确认所需的最低速度等级

根据拍摄内容确定所需的速度等级。不同拍摄场景对写入速度的要求差异显著：

| 拍摄场景 | 最低要求 | 推荐规格 |
| :--- | :--- | :--- |
| 日常照片（单拍） | C10 / U1 | V10 / V30 |
| RAW 格式连拍 | U3 / V30 | V30 / V60 |
| 1080p 全高清视频 | C10 / U1 | V10 / V30 |
| 4K 30fps 视频 | U3 / V30 | V30 |
| 4K 60fps 高码流 | V60 | V60 |
| 8K 视频 / RAW 内录 | V90 | V90 |

### 第三步：确定容量需求

根据以下因素估算所需容量：单张照片或单分钟视频的文件大小、单次拍摄的照片张数和视频时长、是否需要双卡备份，以及是否具备中途换卡和现场备份的条件。

| 拍摄内容 | 推荐容量 | 说明 |
| :--- | :--- | :--- |
| 日常照片拍摄 | 64GB – 128GB | 足够数百至数千张照片 |
| 活动/婚礼摄影 | 128GB – 256GB | 需考虑连拍和备用 |
| 4K 视频拍摄 | 128GB – 256GB | 高码流视频体积大 |
| 8K / RAW 视频 | 256GB – 1TB+ | 文件体积巨大 |
| 双卡备份 | 两张同容量卡 | 安全冗余优先 |

### 第四步：品牌与预算平衡

在确认卡型、速度和容量之后，在预算范围内选择可靠的品牌。高品质存储卡虽然价格更高，但在数据安全性上更有保障。

## 二、不同用户类型的选购方案

### 入门摄影爱好者

**设备**：入门级单反或微单，以 JPEG 格式拍摄为主，偶录 1080p 视频。

**推荐卡型**：SDHC/SDXC（UHS-I），容量 64GB–128GB，速度等级 V30。一张 128GB V30 卡可存储数千张 JPEG 照片，性价比极高。

### 进阶摄影爱好者

**设备**：中端微单/单反，拍摄 RAW + JPEG，经常连拍，录制 4K 视频。

**推荐卡型**：SDXC（UHS-II），容量 128GB–256GB，速度等级 V60。UHS-II 卡的双排金手指接口可提供更快的读写速度，V60 确保 4K 视频流畅录制。

### 视频创作者

**设备**：以视频为主要创作方式，录制 4K 60fps 高码流视频，可能涉及 Log 格式。

**推荐卡型**：SDXC（UHS-II），容量 256GB–512GB，速度等级 V60/V90。视频文件体积大，V60 或 V90 保证持续写入不掉速。建议采用双卡方案——“拍摄中一张卡写满前可无缝切换到另一张”。

### 专业摄影师 / 商业拍摄

**设备**：旗舰机型，大量 RAW 连拍，可能涉及 8K 视频录制。

**推荐卡型**：根据相机卡槽选择 CFexpress Type A 或 Type B，容量 128GB–512GB，优先考虑 VPG400 认证产品。专业制作需兼顾速度、容量和稳定性。

### 运动相机 / 无人机用户

**设备**：GoPro、DJI Action、大疆无人机等。

**推荐卡型**：MicroSDXC（UHS-I），容量 128GB–256GB，速度等级 V30。需注意选择“高耐用性”或“监控专用”型号——运动相机和无人机持续写入数据，对卡的耐用性要求更高。

## 四、多卡配置策略

### 单卡方案

最简单经济的方案，适合日常拍摄和低风险项目。选用大容量、高速的存储卡，一张卡覆盖整场拍摄。

### 双卡方案

**同时录制**：两张卡同时记录相同内容，一张损坏时另一张仍有备份，数据安全性最高。

**扩展录制**：一张卡写满后自动切换到另一张，适合长时间录制场景。

**分类存储**：一张存 RAW，一张存 JPEG，便于后期分工处理。

### 多卡轮换方案

准备 3-5 张存储卡，在活动间隙轮换使用。适用于长时间拍摄项目，避免单卡容量不足或卡故障导致工作中断。

## 五、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：直接在相机菜单里看“剩余张数”决定是否换卡。**

不同格式和画质设置下，剩余张数估算可能不准。在重要活动前，应使用电脑确认存储卡的实际可用容量。

**误区二：买容量最大的卡最划算。**

大容量卡一旦损坏，损失的素材量更大。在关键项目中，两张 128GB 卡的安全性和灵活性优于一张 256GB 卡。

**误区三：所有 SD 卡读卡器都是一样的。**

高速卡（如 UHS-II）需要配套支持对应速度等级的读卡器才能发挥性能。使用旧读卡器可能导致传输速度被限制在低速。

**误区四：存储卡可以在任何设备间随意互换。**

在不同相机和读卡器之间频繁插拔可能导致文件系统错误。格式化前务必确认卡内数据已备份。
:::

## 总结

存储卡的选购需要依次确认相机支持的卡型、拍摄所需的速度等级、合理的容量规划和预算范围。根据用户类型和拍摄场景选择匹配的存储方案，在预算内优先考虑可靠品牌。对于关键项目，多卡方案和双卡备份策略可有效降低数据丢失的风险。多张中等容量卡的安全性优于单张大容量卡，速度等级比峰值速度更能保障视频录制的稳定性。
