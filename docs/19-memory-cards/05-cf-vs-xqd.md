# 19.05 CF 卡与 XQD 卡

## 核心概念概述

CF 卡（CompactFlash）和 XQD 卡是专业摄影存储卡发展历程中的两个重要里程碑。CF 卡诞生于 1994 年[reference:0]，曾是专业数码单反相机长达二十年的行业标准[reference:1]。XQD 卡于 2011 年由 CF 卡协会正式发布[reference:2]，旨在以更小的体积和更高的速度取代 CF 卡[reference:3][reference:4]。

然而，XQD 卡未能完全实现这一目标。随着 CFexpress 标准的兴起，XQD 卡在市场中逐渐被 CFexpress Type B 取代[reference:5]。如今，CF 卡和 XQD 卡都已不再是新型号相机的主流配置，但大量仍在服役的老旧专业相机依然依赖这两种存储介质。理解它们的规格与定位，对于使用老款设备的摄影师和从事设备管理的团队仍具有重要意义。

## 一、CF 卡：曾经的行业标准

### 历史与定位

CF 卡（CompactFlash）由 SanDisk 公司于 1994 年率先推出[reference:6]。CompactFlash 协会（CFA）于 1995 年成立，负责制定和推广 CF 卡规范[reference:7]。

CF 卡采用标准的 **50 针接口**，与 ATA/IDE 协议兼容[reference:8]。长期以来，它一直是专业数码相机（如高端单反）和工业设备领域的主流存储介质[reference:9]。CF 卡主要分为 Type I 和较厚的 Type II 两种物理规格[reference:10]。

### 规格演进

CF 卡的规范持续迭代，速度不断提升[reference:11]：

| CF 规范版本 | 发布时间 | 接口/模式 | 最高传输速度 |
| :--- | :--- | :--- | :--- |
| v1.0 | 1995 年 | PIO Mode 2 | 8.3 MB/s[reference:12] |
| v2.0 | 2003 年 | PIO Mode 4 | 16.7 MB/s[reference:13] |
| v3.0 | 2004 年 | UDMA Mode 4 | 66 MB/s[reference:14][reference:15] |
| v4.0 | 2006 年 | UDMA Mode 6 | 133 MB/s[reference:16] |
| v5.0 | 2010 年 | UDMA Mode 6（48-bit LBA） | 133 MB/s[reference:17] |
| v6.0 | 2010 年 | UDMA Mode 7 | 167 MB/s[reference:18][reference:19] |

CF 5.0 标准将寻址空间增加到 48bit，理论最大容量提升至 144PB[reference:20]。CF 6.0 标准支持 UDMA mode 7，最高传输速度达 167MB/s[reference:21][reference:22]。至 2023 年，CF 规范已发展至 CF 7.0[reference:23]。

### 速度标识方式

CF 卡的速度常以倍速（X）或 UDMA 模式标识。UDMA 7 模式的理论速度最高可达 167MB/s[reference:24]。常见倍速标识如 133x、300x、1000x 等，对应的速度约为 20MB/s、45MB/s、150MB/s[reference:25]。

### 适用机型与现状

CF 卡广泛搭载于佳能、尼康等品牌的老款专业单反相机中。随着 SD 卡性能的提升和 CFexpress 新标准的出现，新发布的相机已不再配备 CF 卡槽。CF 卡目前主要仍在使用老旧机型的摄影师群体中使用。

## 二、XQD 卡：CF 卡的挑战者

### 历史与定位

XQD 卡由索尼、闪迪和尼康等厂商共同研发[reference:26]，于 2011 年 12 月 8 日由 CF 卡协会正式发布[reference:27][reference:28]。该标准采用 **PCI Express 接口技术**，设计目标为替代 CF 卡，具备更小体积、更高传输速度及更大容量[reference:29][reference:30]。首批样品于 2012 年 2 月在日本“CP+ 2012”展会亮相[reference:31]。

### 物理规格

XQD 卡的物理尺寸为 **38.5mm × 29.8mm × 3.8mm**[reference:32][reference:33]，体积约为 CF 卡的一半[reference:34]，比 SD 卡略大[reference:35]。存储卡采用了 7×3 组的金手指设计，避免了 CF 卡针脚易损坏的问题[reference:36]。

### 性能演进

XQD 卡的性能随产品迭代不断提升：

| 阶段 | 读取速度 | 写入速度 | 说明 |
| :--- | :--- | :--- | :--- |
| 首批产品（2012年） | 125 MB/s | 125 MB/s | 索尼 16GB/32GB 版本[reference:37][reference:38] |
| XQD 2.0 规范 | 1000 MB/s（接口能力） | — | PCIe Gen2[reference:39][reference:40] |
| 索尼 G 系列 | 440 MB/s | 400 MB/s | 主流高速型号[reference:41][reference:42] |
| 雷克沙 2933X | 440 MB/s | 400 MB/s | 128GB 版本[reference:43][reference:44] |

XQD 卡设计容量可超过 2TB[reference:45]。产品特性包含防水、抗冲击结构及错误检测纠正功能[reference:46]。

### 适用机型

XQD 卡主要搭载于尼康的专业机型中。尼康 D4 是首款支持 XQD 卡的单反相机[reference:47]。尼康 D5 相机 90% 的机型采用 XQD 卡槽[reference:48]。此外，索尼的部分专业摄录机（如 PXW-Z100、PXW-FS7）也支持 XQD 卡[reference:49]。

XQD 卡需搭配专用读卡器使用[reference:50]。

## 三、CF 卡与 XQD 卡的核心对比

| 对比维度 | CF 卡 | XQD 卡 |
| :--- | :--- | :--- |
| 发布时间 | 1994 年[reference:51] | 2011 年[reference:52] |
| 接口类型 | 50 针 ATA/IDE[reference:53] | PCI Express[reference:54] |
| 物理尺寸 | 43×36×3.3mm | 38.5×29.8×3.8mm[reference:55] |
| 体积 | 较大 | 约为 CF 卡一半[reference:56] |
| 最高速度（实际产品） | 167 MB/s（UDMA 7）[reference:57] | 440 MB/s[reference:58] |
| 接口可靠性 | 针脚式，易损坏[reference:59] | 金手指式，更耐用[reference:60] |
| 主要适用品牌 | 佳能、尼康（老款） | 尼康、索尼（专业机型） |
| 当前状态 | 已基本淘汰 | 正被 CFexpress 取代 |

## 四、XQD 与 CFexpress Type B 的关系

XQD 卡与 CFexpress Type B 卡在物理尺寸上完全一致（均为 38.5×29.8×3.8mm）[reference:61][reference:62]。两者采用相同的接口设计，因此许多支持 XQD 卡的相机（如尼康 Z 系列早期机型）可通过固件更新实现对 CFexpress Type B 卡的兼容[reference:63][reference:64]。

但两者在内部协议上存在本质差异：XQD 采用 PCIe Gen2 接口，而 CFexpress Type B 采用 PCIe Gen3 或 Gen4 接口[reference:65]。因此，**XQD 读卡器无法读取 CFexpress Type B 卡**[reference:66][reference:67]。若计划从 XQD 升级至 CFexpress，需同时购买新的读卡器[reference:68]。

CFexpress 本质上是 XQD 的下一代标准，提供更快的速度、更大的容量和更低的每 GB 成本[reference:69][reference:70]。

## 五、选购建议

### CF 卡用户

若您仍在使用搭载 CF 卡槽的老款单反相机，建议选购 UDMA 7 规格的 CF 卡以获得最佳性能[reference:71]。容量方面，128GB 以内的 CF 卡较为常见[reference:72][reference:73]。需注意确认相机支持的 CF 卡类型（Type I 或 Type II）[reference:74]。

### XQD 卡用户

若您仍在使用搭载 XQD 卡槽的尼康或索尼专业机型，可考虑通过固件升级的方式过渡至 CFexpress Type B 卡[reference:75]。若坚持使用 XQD 卡，建议选购索尼 G 系列或雷克沙 2933X 等高速型号[reference:76]。

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：XQD 卡和 CFexpress Type B 卡完全通用。**

虽然两者物理尺寸相同，但并非所有 XQD 卡槽都兼容 CFexpress Type B 卡。需确认相机厂商是否发布了支持 CFexpress 的固件更新[reference:77]。同时，XQD 读卡器无法读取 CFexpress 卡[reference:78]。

**误区二：CF 卡和 CFexpress 卡是同一类产品。**

CF 卡（CompactFlash）和 CFexpress 卡虽然名称相似，但两者是完全不同的标准[reference:79]。CF 卡采用 50 针 ATA/IDE 接口[reference:80]，CFexpress 采用 PCIe 接口[reference:81]。两者物理尺寸和接口均不通用。

**误区三：XQD 卡已经完全被淘汰。**

XQD 卡虽然不再是新型号相机的标配，但大量尼康和索尼的老款专业机型仍在服役中[reference:82][reference:83]。在二手市场和部分专业领域，XQD 卡仍有实际需求。
:::

## 总结

CF 卡和 XQD 卡代表了专业摄影存储卡的两个重要时代。CF 卡以 50 针 ATA/IDE 接口和 UDMA 模式统治了专业单反市场长达二十年[reference:84]；XQD 卡以 PCIe 接口和更小的物理尺寸试图取代 CF 卡[reference:85][reference:86]，但最终被性能更强的 CFexpress 标准所超越[reference:87]。如今，两者都已不再是主流，但理解它们的规格与定位，对于管理老旧设备和处理历史素材仍具有实际意义。
