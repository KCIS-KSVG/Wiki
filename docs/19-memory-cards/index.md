# 19 摄影存储卡与数据记录设备 概述

## 本章定位与学习目标

存储卡是摄影设备中最基础、也最容易忽视的环节。一张存储卡的性能直接影响相机的连拍续航、视频录制的稳定性以及素材的安全性。在需要连续高强度拍摄的场景中，存储卡的速度和可靠性甚至比相机的像素数更重要。

本章将系统讲解各类存储卡的标准与规格，包括 SD 卡、CFexpress 卡、XQD 卡等主流类型的速度等级、容量选择、格式化方法及选购指南，帮助读者在实际拍摄中做出合理的存储决策。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 速度等级决定拍摄能力上限

存储卡的速度等级直接决定了相机能够支持的拍摄模式。低速卡在高速连拍时可能触发缓存写满，导致相机暂停拍摄；在视频录制中，速度不足则会导致录制中断。在多机位长时间录制前，确认所有存储卡的速度等级满足项目需求，是保障录制不中断的前提。

### 容量规划保障录制连续性

存储卡的容量决定了单次拍摄的续航时间。在长时间活动录制中，需提前计算所需存储容量，并准备备用卡以便在活动间隙更换。在多机位项目中，各机位的存储卡容量应统一规划，避免某一机位提前写满而其他机位仍有剩余空间。

### 格式化是保障稳定性的关键

存储卡应在每次重要拍摄前在相机内完成格式化，而非使用电脑格式化。相机格式化会按照机身最优的文件系统参数进行初始化，确保写入速度与相机缓存匹配，降低录制中断的风险。
