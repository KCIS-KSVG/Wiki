# 10.04 Proxy 代理文件工作流

## 核心概念概述

代理文件（Proxy File）是指将原始高分辨率、高码流的视频素材，转码为低分辨率、低码流的替换文件，在剪辑过程中使用这些轻量级文件进行操作，在最终输出时自动切换回原始素材进行渲染。

代理文件工作流的核心理念是“用轻量级文件完成剪辑决策，用原始文件完成最终输出”。这一工作流解决了高码流素材在剪辑时对电脑性能要求过高的问题，使剪辑过程流畅顺滑，同时不牺牲最终输出的画质。

## 一、为什么需要代理文件

### 高码流素材的剪辑挑战

4K 及以上分辨率的视频素材在剪辑时对电脑性能要求极高——解码高码流 H.264/H.265 文件需要大量 CPU/GPU 算力，多轨叠加时实时预览可能卡顿甚至无法播放，调色和特效处理时响应缓慢，严重影响剪辑效率。

### 代理文件的解决方案

代理文件通过生成低分辨率的替换素材，使剪辑过程的计算负荷大幅降低，预览流畅、多轨操作无卡顿，剪辑效率恢复到可接受的水平。导出时自动使用原始素材进行最终渲染，画质不受任何影响。

## 二、代理文件的原理与流程

### 工作流程概述

代理工作流的基本流程包含四个步骤：

第一步是生成代理文件。将原始素材通过剪辑软件或专用工具转码为低分辨率版本。

第二步是用代理文件进行剪辑。在剪辑软件中切换至代理模式，所有剪辑操作都在轻量级代理文件上进行。

第三步是调色与特效处理。若涉及精细调色或特效合成，可暂时切换回原始素材进行精准调整，或直接使用原始素材。

第四步是最终输出。渲染输出时剪辑软件自动引用原始素材进行编码，输出最高画质的成片。

### 代理文件与原始素材的对应关系

代理文件与原始素材必须保持文件名一致、时间码一致。剪辑软件通过文件名和时间码建立一一对应关系，确保代理文件上的所有剪辑操作都能精确映射回原始素材。

## 三、常见代理文件规格

| 原始素材 | 代理分辨率 | 编码格式 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 4K 高码流 | 1080p 或 720p | ProRes Proxy / DNxHD LB | 专业剪辑 |
| 4K Log / RAW | 1080p | ProRes Proxy | 调色项目 |
| 长时间多机位 | 720p 或 540p | H.264 低码流 | 快速粗剪 |

## 四、代理文件的生成方法

### 方法一：软件内自动生成

多数专业剪辑软件支持导入素材时自动生成代理文件。

**Premiere Pro**：导入素材后选中文件，右键选择“代理”→“创建代理”，选择预设格式（如 ProRes Proxy），后台自动转码。

**DaVinci Resolve**：在媒体页面选中素材，右键选择“生成代理文件”，选择代理分辨率和格式。

**Final Cut Pro**：导入素材时勾选“创建优化媒体”或“创建代理媒体”，FCP 自动在后台生成。

**剪映专业版**：导入素材后，在素材管理区选中文件，右键选择“生成代理”或“优化”，可在设置中自定义代理分辨率和位置。

### 方法二：导入时自动生成

在项目设置中预先配置代理生成规则。导入素材时软件自动在后台生成代理文件，无需手动逐个操作，适合批量处理大量素材。

### 方法三：外部工具批量生成

使用 Shutter Encoder、Media Encoder 或 FFmpeg 等工具批量转码，将转码后的代理文件放入指定文件夹，在剪辑软件中手动链接。

## 五、各软件中代理文件的使用方法

### Premiere Pro

创建代理后，在节目监视器下方点击“切换代理”按钮，开启后剪辑使用代理文件。导出时软件自动使用原始素材，无需手动切换。

### DaVinci Resolve

生成代理后，在播放菜单中选择“使用代理文件”即可。调色时如需查看原始画质，可临时关闭代理模式。

### Final Cut Pro

在素材管理区点击代理文件图标即可切换。FCP 的代理管理较为自动化，切换方便。

### 剪映专业版

在预览窗口右下角点击“性能”按钮，可选择优先画质或优先流畅。开启代理后，预览流畅度显著提升，导出时自动使用原始素材渲染。

## 六、代理文件的存储与管理

### 存储位置

建议将代理文件存放在与原始素材不同的存储位置。常见做法是在项目文件夹下创建「01_项目文件/代理文件」子文件夹，统一存放所有代理文件，与原始素材分开管理。

### 命名规范

代理文件应保持与原始素材相同的文件名（仅扩展名可能不同）。剪辑软件通过文件名和元数据匹配代理与原始素材，因此修改代理文件名会导致无法链接。

### 清理时机

项目交付后，若确定不再需要重新剪辑，可删除代理文件以释放存储空间。若项目可能进行修改或重新调色，建议保留代理文件。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：代理文件会降低最终输出的画质。**

代理文件仅在剪辑过程中使用。导出时剪辑软件自动引用原始素材进行渲染，输出的画质由原始素材决定，不受代理文件影响。

**误区二：只有 4K 素材才需要代理文件。**

高码流 1080p 素材（如 50Mbps 以上）在低配电脑上同样可能导致剪辑卡顿。代理文件的应用场景不限于 4K，任何导致剪辑不流畅的素材都可考虑使用代理。

**误区三：生成代理文件需要占用额外存储空间，是浪费。**

代理文件确实占用存储，但通常体积较小（约为原始素材的 10%-20%）。对于高码流项目，代理文件带来的剪辑效率提升远超其存储成本。
:::

## 总结

代理文件工作流通过生成低分辨率的替换素材，使剪辑过程流畅顺滑，在最终输出时自动切换回原始素材保证画质。Premiere Pro、DaVinci Resolve、Final Cut Pro 和剪映专业版均支持代理工作流，生成和切换方式各有差异。在高码流、多机位和复杂项目中，代理文件是提升后期效率的必要工具。
