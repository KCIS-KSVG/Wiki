# 07 相机设备与摄影器材 概述

## 本章定位与学习目标

相机设备是摄影创作的物质基础。不同类型的相机在结构设计、性能侧重和适用场景上存在显著差异——从适合静态摄影的单反相机，到兼顾照片与视频的微单相机，再到专为动态影像设计的电影摄影机，以及轻便耐用的运动相机。

理解各类设备的核心特点与适用场景，是合理配置器材、高效完成拍摄任务的前提。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 设备选择的场景驱动逻辑

不同拍摄场景对设备的要求不同。体育赛事需要高速对焦和连拍能力，适合旗舰级微单或单反。舞台演出录制需要高感光性能和视频功能，适合全画幅微单。多机位直播需要长时间稳定运行，需要具备良好散热能力的设备。

### 视频能力的差异化需求

静态摄影和视频拍摄对设备的要求不同。静态摄影优先高像素、高动态范围、高连拍速度。视频拍摄优先视频画质、编码格式、散热能力、Log支持和长时间录制稳定性。

### 防抖与稳定性的重要性

手持拍摄中防抖系统直接影响出片率。机身防抖配合镜头防抖，可在低速快门下手持拍摄获得清晰画面。在体育和户外活动中，稳定的画面比极致画质更重要。
