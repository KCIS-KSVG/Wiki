# 07.01 单反 DSLR vs 微单 Mirrorless

## 核心概念概述

单反（DSLR）和微单（Mirrorless）是目前可换镜头相机市场两大主流类型。两者最本质的区别在于内部结构——单反通过反光镜和五棱镜实现光学取景，微单则取消反光镜结构，直接通过电子取景器或屏幕显示传感器捕捉的画面。

理解两种系统的结构差异与性能特点，是在选购设备和配置器材时做出合理选择的基础。

## 一、单反相机的核心结构

### 反光镜与光学取景

单反相机的核心特征是“单镜头反光”结构。光线穿过镜头后到达倾斜45度的反光镜，被反射向上进入五棱镜，经过多次全反射后从目镜射出，拍摄者通过光学取景器（OVF）看到来自镜头的实时影像。

按下快门时，反光镜向上翻起，快门幕帘打开，光线直达传感器完成曝光。这一过程中的反光镜弹起动作产生了单反特有的“咔嚓”声。

### 光学取景的优势与局限

光学取景器零延迟、无耗电，在长时间待机拍摄中优势明显。但光学取景器无法预览实际曝光效果、白平衡和景深（需使用景深预览按钮），且在暗光环境下取景器亮度有限。

### 相位检测对焦模块

单反在反光镜下方设有独立的相位检测对焦模块，通过副反光镜分光进行测距。相位检测对焦速度极快，适合体育和运动拍摄。

但独立对焦模块的覆盖范围有限（集中在画面中央区域），且对焦模块与传感器之间的光路差异可能导致“对焦偏移”（需AF微调）。

## 二、微单相机的核心结构

### 无反光镜的设计

微单取消了反光镜和五棱镜，光线直接照射到图像传感器上。传感器同时承担成像、取景和对焦三大功能——实时画面显示在电子取景器（EVF）或背部屏幕上，相位检测像素集成在传感器上完成对焦测距。

### 电子取景的优势

电子取景器实时显示传感器的画面，所见即所得——曝光补偿、白平衡、色彩风格均可预览。可利用峰值对焦和放大对焦等辅助工具辅助手动对焦。在暗光环境下可增益显示，比光学取景器更明亮。

电子取景的局限在于存在微小延迟（高端机型已降至极低），且持续耗电影响续航。

### 片上相位检测

微单的相位检测像素直接集成在图像传感器上，覆盖范围广（几乎整个画面），且对焦与成像光路一致，不存在对焦偏移问题。

## 三、单反与微单的核心差异

| 对比维度 | 单反（DSLR） | 微单（Mirrorless） |
| :--- | :--- | :--- |
| 反光镜 | 有 | 无 |
| 取景方式 | 光学取景（OVF） | 电子取景（EVF） |
| 法兰距 | 较长（约44-46mm） | 较短（约16-20mm） |
| 机身尺寸 | 较大较重 | 较小较轻 |
| 对焦系统 | 独立相位检测模块 | 片上相位检测 |
| 对焦覆盖范围 | 集中在中央区域 | 几乎覆盖整个画面 |
| 视频对焦性能 | 相对较弱 | 较强 |
| 电池续航 | 较长（不取景耗电） | 较短（持续电子取景） |

## 四、单反与微单的适用场景

### 单反适用的场景

**体育与运动摄影：** 光学取景零延迟，对焦速度快，适合高速连拍和追踪移动目标。

**长时间待机拍摄：** 光学取景不耗电，电池续航优势明显。

**二手与预算有限：** 二手单反市场成熟，镜头群庞大且价格较低。

### 微单适用的场景

**视频拍摄：** 电子取景所见即所得，片上相位检测对焦平滑，适合视频自动对焦需求。

**弱光与旅行摄影：** 电子取景暗光增益显示，小体积便于携带。

**手动对焦与转接：** 峰值对焦与放大对焦辅助，法兰距短便于转接各种老镜头。

**活动与会议记录：** 静音电子快门适合安静场合，人脸/眼部识别提升对焦效率。

## 五、迁移成本与系统选择

单反用户迁移至微单时需考虑镜头转接环的兼容性。转接环支持原有镜头自动对焦（性能可能略有下降），但转接后体积不再小巧。

新用户可直接进入微单系统，获得最新的对焦技术和视频功能。

## 六、实战建议

**体育赛事：** 优先考虑旗舰级单反或旗舰级微单。两者均可胜任，但需注意电池备用量。

**会议与活动记录：** 微单优先，电子取景所见即所得便于快速调整参数，静音快门适合安静场合。

**舞台演出录制：** 微单优先，视频对焦性能强，配合眼部识别确保主体合焦。

**照片为主、视频为辅：** 两者皆可。单反在照片拍摄中依然出色，微单在视频方面占优。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：单反已经被淘汰，不值得购买。**

单反并未淘汰。在体育、生态等需要高速对焦和长续航的场景中，单反依然表现出色。大量专业体育摄影师仍在使用旗舰单反。

**误区二：微单的电子取景器延迟会影响体育拍摄。**

现代旗舰微单的EVF延迟已降至极低（人眼无法察觉），配合强大的追踪对焦能力，足以胜任体育赛事拍摄。

**误区三：转接环会完全丧失自动对焦性能。**

现代转接环在多数主流品牌之间已实现良好的自动对焦支持，但性能可能略低于原生镜头。转接时需查阅兼容性信息。
:::

## 总结

单反与微单的核心差异在于反光镜结构，这决定了取景方式、对焦系统和机身尺寸的不同。单反以光学取景和长续航见长，适合体育和长时间拍摄；微单以电子取景所见即所得和视频对焦性能见长，适合视频制作和活动记录。选择哪种系统，取决于主要拍摄场景和个人使用习惯。
