# 22.05 活动摄影现场执行标准

## 核心概念概述

现场执行是将拍摄计划转化为实际成果的关键环节。无论前期准备多么充分，现场的决策和操作质量直接决定了最终素材的品质。

现场执行标准是指在不同类型的活动拍摄中，团队应遵循的统一操作规范——从进场架设到参数设定，从拍摄执行到设备撤收。建立并遵守现场执行标准，可以确保多机位项目的素材一致性，减少现场决策的随机性，提升整体的出片率和素材可用性。本章将系统讲解活动摄影现场执行的核心标准与操作规范。

## 一、进场与架设标准

### 进场时间安排

在活动开始前，团队应有充足的进场和架设时间。不同类型活动所需的时间不同：

| 项目类型 | 建议进场时间 | 说明 |
| :--- | :--- | :--- |
| 班代会/会议 | 提前 30-45 分钟 | 熟悉场地、选定机位 |
| 音乐厅/舞台演出 | 提前 1.5-2 小时 | 彩排前完成架设和参数设定 |
| 体育赛事 | 提前 30 分钟 | 选定拍摄位置，完成相机设定 |
| 校庆/户外活动 | 提前 1 小时 | 多机位架设、飞行前检查 |

### 机位架设顺序

1. **确定主机位位置**：优先架设主机位（全景机位），这是多机位项目的基准。
2. **铺设主信号线缆**：从各机位到导播台或录机位置铺设线缆，使用大力胶固定。
3. **确认各机位覆盖范围**：通过监视器或取景器确认各机位的拍摄范围无重叠也无遗漏。
4. **标记机位位置**：用大力胶在地面标记三脚架位置，防止被意外移动。

### 场地勘查要点

- 确认电源接口位置，规划供电方案
- 确认拍摄区域是否有限制或禁区
- 确认是否有遮挡物影响机位视线
- 确认现场灯光类型和色温

## 二、多机位参数统一标准

在多机位项目中，参数统一是后期剪辑的基础。各机位参数不一致将导致画面色彩、亮度和运动模糊不一致，严重影响成片质量。

### 视频拍摄参数统一

**制式与帧率**：所有机位统一设定为 PAL（中国大陆标准）或 NTSC，帧率保持一致（如 25fps）。

**快门速度**：统一设定为帧率的两倍分之一（180 度快门原则），25fps 用 1/50s，50fps 用 1/100s。体育赛事中如需更高快门速度，各机位需同步调整。

**白平衡**：统一设定为手动 K 值，避免使用自动白平衡。根据现场灯光类型设定对应的色温值，各机位使用相同 K 值。

**对焦模式**：固定机位统一使用手动对焦，游走机位可根据需要使用 AF-C。

**画面风格**：关闭自动对比度增强、自动色彩增强等功能。如有 Log 模式，统一决定是否使用。

### 照片拍摄参数统一

**白平衡**：与视频保持一致，统一手动 K 值。

**色彩模式**：统一使用相同的色彩风格预设。

**图片格式**：统一决定使用 RAW 或 JPEG+RAW。

### 参数统一的检查流程

在彩排或活动开始前，各机位负责人应完成自检，并由现场负责人逐一确认所有机位的参数设定一致。建议使用检查表记录各机位的设定值。

## 三、拍摄执行规范

### 固定机位规范

固定机位在活动开始后应满足以下要求：

- 演出开始后严禁关机、严禁变焦、严禁移动
- 全程保持录制或待命状态
- 注意观察录制指示灯（REC 红点亮起），确认正在记录
- 在节目间歇确认存储卡剩余容量

### 游走机位规范

游走机位在移动拍摄中应遵守以下规范：

- 在不干扰活动参与者的情况下灵活移动
- 根据 Shot List 预判关键瞬间，提前就位
- 注意安全，不遮挡观众视线，不进入演员动线
- 适时检查存储卡和电池状态

### 关键瞬间的捕捉

在活动拍摄中，关键瞬间的捕捉决定了一组照片的品质。执行标准要求：

- 在彩排或开场前了解活动流程，预判每个环节的高光时刻
- 保持专注，在关键环节前完成构图和参数设置
- 对可预判的瞬间（如致辞开场、颁奖握手、谢幕鞠躬）提前就位
- 对不可预判的瞬间（如即兴互动、意外反应）保持敏感度

## 四、特殊场景执行标准

### 音乐厅/舞台演出

- 所有机位统一至 25fps、1/50s、白平衡 K 值
- 固定机位全程不关机、不变焦、不移动
- 主机位（中央全景）负责主音频录制，其他机位配合切换
- 在节目间歇（报幕、换场）各机位可快速检查存储卡状态
- 严禁使用闪光灯和任何补光设备

### 班代会/阶梯教室会议

- 使用电子快门和静音拍摄模式
- 投影屏幕环境下白平衡建议设置在 4000K 左右
- 确保每位发言人至少有 2-3 张可用的近景/中景照片
- 注意避免投影屏幕反光影响人脸曝光

### 体育赛事（室内场馆）

- 快门速度不低于 1/500s，建议 1/1000s
- 使用高速连拍和 AF-C 连续自动对焦
- 运动相机固定位全程录制，使用外接电源
- 照片拍摄为主，视频录制为辅助兜底

### 校庆/户外活动

- 各环节有明确的拍摄分工，避免交叉或遗漏
- 高空展示项目（攀岩、滑索）需提前就位并开启高速连拍
- 航拍须保持安全距离，注意规避障碍物（滑索钢缆等）
- 无人机飞行须配备目视观察员

## 五、活动结束撤收标准

### 设备停止与记录保存

- 各机位在接到撤收指令后停止录制
- 确认所有录制文件已保存，设备无异常
- 取出存储卡前确认录制指示灯已熄灭

### 撤收流程

1. 按设备清单逐项回收设备
2. 重点检查快装板、镜头盖、存储卡等小件物品
3. 撕除地面所有大力胶标记
4. 检查场地是否有遗留个人物品
5. 如为团队项目，各小组长确认本组设备已全部回收

### 设备状态记录

如有设备故障、异常或需维修，在撤收时记录并汇报。

## 六、常见问题与应急处理

| 问题 | 应急处理 |
| :--- | :--- |
| 某机位存储卡满 | 利用节目间隙更换备用卡，或切换至备用录制设备 |
| 某机位电池耗尽 | 使用备用电池更换，优先保障主机位 |
| 信号线缆意外断开 | 检查并重新连接，导播台切换至其他可用机位 |
| 设备过热 | 暂停使用，移至通风处降温（避免风扇直吹镜头） |

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：参数统一只需要各机位自己设定即可，无需确认。**

参数统一需要确认而非“各自设定”。不同人对同一设定的理解可能存在差异，建议各机位设定完成后，由一人逐一确认所有设定值。

**误区二：固定机位在间歇期可以关机省电。**

固定机位在间歇期关机可能导致重新开机时错过后续环节的开始瞬间。建议在间歇期保持待机状态，仅在明确较长休息时间（如 30 分钟以上）时考虑关机。存储卡和电池的更换应在间歇期快速完成，而非关机。

**误区三：活动结束后可以放松警惕，慢慢撤收。**

活动结束后人员疲惫，注意力下降，是最容易遗留设备的时间段。撤收时应保持与进场时相同的严谨态度，按清单逐项核对，避免因疲惫而遗忘重要设备。
:::

## 总结

活动摄影现场执行标准涵盖进场架设、参数统一、拍摄执行和撤收全流程。在进场阶段需确保充足的准备时间和规范的架设顺序；在多机位项目中，制式、帧率、快门速度、白平衡等参数必须在所有机位上统一；在执行阶段，固定机位保持稳定、游走机位灵活预判、关键瞬间精准捕捉；在撤收阶段，按清单逐项核对是防止设备遗留的最后一道防线。不同类型活动（音乐厅、会议、体育、校庆）有各自特殊的执行要点，需根据实际情况调整执行标准，确保素材质量的一致性和可靠性。
