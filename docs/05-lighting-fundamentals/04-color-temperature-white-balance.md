# 05.04 色温与白平衡调整

## 核心概念概述

色温是描述光源颜色的物理量，白平衡是相机校正光源色温以确保白色物体呈现白色的功能。两者共同决定了照片的色彩基调。

在不同光源条件下拍摄时，相机的白平衡设置必须与现场光源色温匹配，才能获得准确的色彩还原。理解色温与白平衡的关系，是在混合光源环境中实现色彩精准控制的关键。

## 一、色温的物理原理

### 色温的定义

色温是指将一个理想黑体加热到某一温度时，其发出的光的颜色与该光源颜色相同时的温度，单位是开尔文。

低色温光源偏暖（橙黄色），高色温光源偏冷（蓝白色）。常见光源色温参考值如下：烛光约1800-2000K，日出日落约2000-3000K，钨丝灯约2800-3200K，暖白LED约3000-4000K，日光/闪光灯约5200-5600K，阴天约6000-7000K，蓝天约8000-10000K以上。

### 色温对色彩的影响

不同色温的光源照射同一物体时，物体呈现的颜色会发生变化。一张白纸在钨丝灯下呈暖黄色，在日光灯下呈冷白色。人眼会自动校正这种色差，但相机传感器需要白平衡设定才能准确还原。

## 二、白平衡的工作原理

### 白平衡的校正逻辑

白平衡的工作逻辑是：相机识别画面中的白色或中性灰色区域，然后调整红、绿、蓝通道的增益，使该区域在最终图像中呈现为中性白色或灰色，同时将这一调整应用到整个画面。

例如，相机检测到画面偏暖（钨丝灯环境），会自动降低红色增益、增加蓝色增益，使白色物体还原为白色。

### 自动白平衡

自动白平衡由相机算法自动判断光源色温并进行校正。在单一光源、色温稳定的环境下，AWB表现良好。但在混合光源或色温变化的环境中，AWB可能产生漂移——同一场景的不同照片色温不一致。

舞台演出、会议记录等多机位拍摄中，自动白平衡可能导致不同机位画面颜色不一致，给后期多机位剪辑带来困难。

### 预设白平衡

相机提供多种预设白平衡模式，对应常见光源类型，包括日光（约5200K）、阴影（约7000K，偏暖补偿）、阴天（约6000K）、钨丝灯（约3200K）、荧光灯（约4000K）、闪光灯（约5500K）。

预设白平衡比AWB更稳定，适合光源类型明确的场景。

### 手动色温设定（K值设定）

通过直接输入色温数值来控制白平衡。这一模式在需要精确控制色彩或多机位色彩统一时最为可靠。拍摄者根据现场光源色温直接设定对应数值，确保所有机位色彩一致。

## 三、色温与白平衡的视觉影响

相同色温不同设定对画面色彩的影响：设定的色温值等于光源色温时，色彩准确还原；设定的色温值高于光源色温时，画面偏暖（偏橙黄）；设定的色温值低于光源色温时，画面偏冷（偏蓝紫）。

## 四、不同场景的白平衡设定策略

**单一光源室内活动：** 若现场为统一的钨丝灯或LED灯，使用对应预设或手动K值设定最为可靠。例如音乐厅统一暖色面光，设定为3200-4000K。

**混合光源会议室/阶梯教室：** 手动K值设定在4000-4500K之间折中处理。配合RAW格式拍摄，后期对主体区域（发言人面部）进行精细色温校正。确保多机位K值完全一致，便于后期统一调色。

**户外晴天：** 使用日光预设或5200-5600K手动设定，色彩准确稳定。

**户外阴天/阴影：** 使用阴天预设或6000-6500K设定，补偿阴天的冷色倾向，使肤色更自然。

**舞台演出：** 舞台灯光色温变化频繁，建议使用手动K值设定（根据主流灯具类型设定）或RAW格式拍摄后期处理。若使用AWB，不同灯光切换时画面颜色可能剧烈变化。

**体育赛事：** 室内体育馆灯光类型固定，设定对应K值后锁定。不建议使用AWB，避免比赛过程中画面色温漂移。

## 五、白平衡的后期调整

RAW格式支持后期无损调整白平衡，后期软件中可以重新设定色温值和色调偏移，效果等同于拍摄时重新设定。JPEG格式的白平衡调整空间有限，过度调整可能导致色彩断层或偏色。

在混合光源场景中，RAW格式拍摄并在后期对画面不同区域分别进行色温校正，是解决复杂色温问题的标准工作流。

## 六、白平衡偏移与创意应用

白平衡不只能用来“校正”色彩，还可以用于“创造”色彩。在拍摄日出日落时将色温设定偏高（暖化效果），强化温暖氛围；在拍摄雪景时将色温设定偏低（冷化效果），强化清冷感。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：自动白平衡可以应对所有光线条件。**

AWB在单一光源环境下表现良好，但在混合光源或色温频繁变化的环境中可能出现漂移。在多机位拍摄中，AWB会导致不同机位画面颜色不一致，严重影响后期剪辑质量。手动K值设定是多机位拍摄的标准做法。

**误区二：后期可以完美修复任何白平衡错误。**

RAW格式下确实可以大幅调整色温，但过度调整（超过±2000K）可能导致色彩断层或偏色。若拍摄时色温偏差过大，后期修复会引入噪点和颜色失真。拍摄时应尽量准确设定白平衡。

**误区三：所有机位使用同一个K值设定就能保证色彩一致。**

同一K值设定在不同品牌、型号的相机上可能呈现略有差异的色彩表现。为保证多机位色彩一致，建议在拍摄前使用色卡进行白平衡统一校准，或在后期以主机位为参考统一调整。
:::

## 总结

色温是光源的物理属性，白平衡是相机校正色彩的功能。两者的匹配决定了照片的色彩准确度。手动K值设定是混合光源和多机位场景中最可靠的白平衡方式，RAW格式拍摄为后期色温调整保留了充分的灵活空间。
