# 05 摄影光线基础与灯光控制 概述

## 本章定位与学习目标

光线是摄影的原材料。没有光，就没有摄影。理解光线的物理特性与视觉表现，是掌握摄影曝光、色彩和氛围营造的基础。

本章将从光线的方向、强度和色彩三个维度，系统讲解光线的基本属性及其对画面的影响，并介绍硬光、柔光、色温控制以及三点布光法等实用灯光技术。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 光线方向决定立体感与氛围

光线的方向决定了被摄体的阴影位置和立体感。顺光使被摄体均匀明亮但缺乏体积感，侧光突出纹理和轮廓，逆光营造戏剧性和分离主体与背景的效果。

### 光源性质决定阴影硬度

硬光产生锐利清晰的阴影边缘，柔光产生过渡自然的渐变阴影。硬光适合强调质感，柔光适合表现柔和肤质和氛围。现场光线条件的判断与应对是关键。

### 色温匹配决定色彩准确度

不同光源具有不同色温，相机的白平衡设置必须与光源色温匹配才能获得准确的色彩还原。在混合光源环境中，色彩管理是最大的技术挑战。

::: tip 💡 现场经验
在阶梯教室或会议室中，现场光线通常为混合光源——天花板日光灯为冷色，投影屏幕为冷白光，讲台面光为暖色聚光。为在这些条件下获得较准确的肤色还原，专业团队会手动设定白平衡在 4000K-4500K 之间，并在后期对 RAW 文件进行精细的色彩校正。
:::
