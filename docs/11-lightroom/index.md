# 11 Adobe Lightroom 照片管理与调色 概述

## 本章定位与学习目标

Adobe Lightroom Classic 是专业摄影师最常用的照片管理与调色工具。与 Photoshop 的单张精修定位不同，Lightroom 面向的是“大批量照片的高效处理”——从导入、筛选、评分到批量调色和导出，Lightroom 为摄影工作流提供了完整的解决方案。

本章将系统讲解 Lightroom 的核心功能模块：Catalog 数据库的原理与导入策略、照片筛选与评分方法、Develop 模块的基础调色工具、预设的使用与制作、以及导出参数的设定。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### Lightroom 的工作流定位

Lightroom 定位于“选片 + 调色 + 导出”的高效工作流，适合处理数百张活动照片的批量任务。对于需要像素级精修的单张照片（如人像皮肤精修、复杂合成），需要配合 Photoshop 使用。

### Catalog 是 Lightroom 的核心

Lightroom 的 Catalog 是一个数据库文件，记录所有照片的预览、编辑历史、关键字和元数据。理解 Catalog 的工作逻辑——照片文件本身不随编辑而改变，所有调整以“指令”形式保存在 Catalog 中——是避免照片丢失和保持工作流清晰的关键。

### 预设提高效率但不替代手动调色

预设可以快速应用统一的色彩风格，但预设无法自动校正曝光偏差和白平衡。在应用预设前，应先将照片的曝光、白平衡等基础参数调整到位，再应用预设作为风格化起点。

::: tip 💡 现场经验
在会议、舞台、体育等活动中，照片数量通常较大（数百至上千张）。高效的工作流是在 Lightroom 中完成“导入 → 筛选 → 评分 → 批量调色 → 导出”的全流程。使用旗标和星级快速标记可用照片，将调色方案同步至同场景照片，最后批量导出，可在较短时间内完成从原始素材到交付成片的完整流程。
:::
