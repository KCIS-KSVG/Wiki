# 01 摄影基础与成像原理 概述

## 本章定位与学习目标

摄影技术是一门横跨物理光学、微电子学与数字信号处理的应用学科。无论你是在安静的室内音乐厅架设长视频主机位、在室外操场跑道上抓拍高速运动的运动员，还是在阶梯教室中记录代表发言，所有现场操作的参数决策（快门速度、白平衡、对焦模式、存储格式），其底层依据都源自本章即将展开的四个核心知识模块：

1. 光学成像：光线如何被透镜折射并汇聚于传感器平面
2. 光电转换：传感器像素点如何将光子能量量化为电压信号
3. 像素与分辨率：高像素与高画质之间的物理权衡
4. 文件格式本质：RAW原始数据与JPEG机内烘焙成片的差异

掌握这些底层原理，你便拥有了脱离“参数试错”的决策能力。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从行业通用的现场操作中，先建立三个贯穿本章的“理论—实践”桥梁。

### 快门速度与人工光源频率的物理匹配

在礼堂、音乐厅或阶梯教室等有交流电照明（50Hz/60Hz）的环境中，快门速度若设置不当，画面会出现横向滚动的明暗条纹（频闪）。行业通行做法是：在中国大陆（PAL制式，50Hz电网）下，快门速度锁定为1/50s、1/100s或1/125s等工频整数分之一，确保每帧捕获的光能总量恒定。

色温（K值）的物理本质是黑体辐射温度——3200K对应钨丝灯，5600K对应正午日光。固定K值而非依赖自动白平衡（AWB），可避免多机位后期剪辑时因白平衡漂移导致颜色跳变。

### 对焦模式选择与传感器原理

固定机位（如舞台全景、会议大全景）通常使用手动对焦（MF）。固定机位的景深范围在超焦距状态下足以覆盖整个舞台，锁死焦点后可彻底杜绝镜头“拉风箱”现象。

手持跟拍运动员、骑手或演讲者时，则依赖传感器上的相位检测像素（PDAF）计算被摄体距离的实时变化速率，配合AF-C（连续自动对焦）与人体/眼部识别算法，在高强度运动中锁住主体。

### 存储卡格式化与文件系统兼容性

专业拍摄任务进场前的标准操作之一，是“在机身内格式化存储卡”。不同品牌相机对exFAT、FAT32或NTFS文件系统的写入策略与缓存簇大小有严格匹配要求。仅在机身内格式化，才能确保数据总线以最优簇大小工作，避免录制4K视频或RAW连拍时因写入延迟导致中断。

::: tip 💡 现场经验
在禁止快门机械声的室内场合（正式会议、管弦乐录制），务必启用电子快门。但需注意其“果冻效应”——若拍摄对象移动过快，建议切回机械快门并配合“静音拍摄”模式。
:::

::: warning ⚠️ 避坑指南
一个易被忽视的错误是将相机设为NTSC制式（60Hz）而在50Hz灯光环境下拍摄，此时画面会出现无法修复的频闪条带。进场架设设备后的第一操作，应是确认机身制式（PAL/NTSC）与当地电网标准一致。
:::
