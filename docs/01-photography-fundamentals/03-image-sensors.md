# 01.03 图像传感器：全画幅/APS-C/M43

## 核心概念概述

图像传感器是数码相机的“光电转换核心”。不同相机之间最根本的差异，往往不在于像素数量的高低，而在于传感器物理尺寸，即画幅的差异。

画幅尺寸决定了三个关键属性：等效视角（同一焦距在不同画幅上看到的范围不同）、景深表现（背景虚化能力）以及高感光度下的画质纯净度（噪点水平）。理解画幅的物理意义，是选购设备和在实际拍摄中选择合适机身的基础。

## 一、主流画幅尺寸分类

目前可换镜头相机的主流画幅分为四类，按尺寸从大到小排列如下：

| 画幅类型 | 尺寸（约） | 裁切系数 | 常见定位 |
| :--- | :--- | :--- | :--- |
| 全画幅 | 36×24mm | 1.0x | 专业摄影旗舰 |
| APS-C | 22×15mm | 1.5x / 1.6x | 准专业/入门级 |
| M4/3 | 17×13mm | 2.0x | 便携微单/视频机 |
| 1英寸 | 13×8mm | 2.7x | 高端卡片机 |

裁切系数指的是该画幅相对于全画幅的焦距等效倍率。例如，一支 50mm 镜头安装在 APS-C 机身上，裁切系数为 1.5x，其等效视角相当于全画幅的 75mm 镜头。安装在 M4/3 机身上则为 100mm 等效视角。这意味着同一支镜头在小画幅机身上能获得更窄的视野，相当于“赚到了”更长的焦距。

## 二、画幅尺寸影响画质的物理根源

### 像素井体积与进光量

画幅尺寸的直接物理优势体现在单个像素的“像素井”体积上。在像素数量相同的前提下，画幅越大的传感器，单个像素的物理面积越大，像素井越深，能容纳的光子数量越多。

这意味着在弱光环境下拍摄时，大画幅传感器的每个像素能收集到更多的光信号，信噪比更高，画面更纯净。全画幅传感器在高 ISO 下的噪点控制通常明显优于 M4/3 传感器。

### 景深与背景虚化

相同光圈和相同构图视角下，画幅越大的传感器所能获得的背景虚化效果越强烈。这是因为大画幅需要使用更长焦距或更近的拍摄距离来实现相同构图，从而产生更浅的景深。

全画幅更容易拍出“主体清晰、背景奶油般化开”的浅景深效果。而 M4/3 即使使用大光圈镜头，景深也相对较深，更适合需要前后景都清晰的场景，如风光、纪录片或活动全景记录。

## 三、各画幅的特点与适用场景

### 全画幅

全画幅是 35mm 胶卷时代的标准尺寸，数码时代沿用为“全尺寸”基准。其高感光度下画质纯净、噪点最少，动态范围宽广，高光与暗部细节保留最好，景深控制力最强。同时无裁切系数，镜头焦距与视角完全对应。

其劣势在于机身与镜头体积大、重量重，整套系统携带负担明显；机身和镜头价格较高；高像素机型对存储卡写入速度和后期电脑性能要求较高。

在需要最高画质的商业拍摄、室内弱光环境如音乐厅和婚礼现场，以及追求极致浅景深的人像摄影中，全画幅是首选。

### APS-C

APS-C 画幅尺寸约为全画幅的一半。其机身和镜头更加轻便便携，价格相对亲民，镜头群丰富。同时可利用裁切系数获得“增距效果”，特别适合拍摄体育、野生动物等需要长焦的场景。

其劣势是高感光度下噪点比全画幅明显，动态范围稍窄，背景虚化能力相对较弱。

APS-C 是大多数摄影爱好者的主流选择，尤其适合预算有限、需要便携性或主攻体育与生态摄影的用户。

### M4/3

M4/3 由奥林巴斯和松下联合推出，画幅尺寸约为全画幅的四分之一。其极致轻便，机身小巧，镜头体积显著小于 APS-C 和全画幅，防抖系统通常非常出色，视频功能强大。

其劣势是弱光环境下噪点明显，动态范围有限，景深较深、背景不易虚化。

M4/3 非常适合旅行摄影、日常随身拍摄和 Vlog 视频创作。在需要长时间手持拍摄或轻量级多机位方案中具有天然优势。

## 四、实际拍摄中的画幅选择逻辑

画幅选择没有“绝对最好”，而是根据场景需求来决定。

室内弱光场景如音乐厅、礼堂和会议室，应优先考虑全画幅或 APS-C 搭配大光圈镜头。室内舞台灯光通常偏暗且色温复杂，大画幅的高感纯净度能为后期提供更多调整空间。

户外体育或运动场景中，APS-C 的裁切系数反而成为优势。70-200mm 镜头在 APS-C 上等效约 105-300mm，能获得更远的“射程”，同时 APS-C 相机相对轻便，便于手持跟拍。

需要全程记录的多机位场景中，M4/3 或 APS-C 的轻量化特性显著减轻脚架和云台的承重要求，更便于长时间固定录制。

::: tip 💡 现场经验
在室内体育馆拍摄篮球、排球等赛事时，现场灯光往往偏暗且无法补光。有经验的团队会选择 APS-C 机身并搭配 F2.8 恒定光圈变焦镜头，利用裁切系数等效获得更远焦距，同时 F2.8 大光圈足以保证 1/500秒以上的快门速度来冻结运动员动作。全画幅固然画质更好，但全套设备的重量对长时间手持拍摄的体力消耗显著增加。
:::

## 五、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：全画幅一定比 APS-C 好。**

全画幅在画质上限上更优，但其重量、价格和后期存储成本也显著更高。APS-C 对多数用户而言是更平衡的选择。判断标准应是“你经常拍摄什么场景”而非“哪个更贵”。

**误区二：画幅越大，像素就一定越高。**

画幅尺寸与像素数量是两个独立概念。全画幅可以做成 2400 万像素，APS-C 也可以做 3200 万像素。高像素 APS-C 的单个像素面积甚至可能小于低像素全画幅，实际高感表现可能反而不如后者。

**误区三：APS-C 机身使用全画幅镜头，画质会变差。**

APS-C 机身使用全画幅镜头时，仅中心区域被利用，边缘部分被裁切掉。镜头中心区域通常光学质量最好、锐度最高、畸变最小，实际画质反而可能提升，边缘暗角也会减轻。唯一的损失是等效视角变窄，同时镜头重量没有减轻。
:::

## 总结

画幅尺寸是相机最基础的物理属性之一，直接影响视角、景深、高感表现和设备便携性之间的平衡。没有“最好”的画幅，只有“最适合你拍摄场景”的画幅。
