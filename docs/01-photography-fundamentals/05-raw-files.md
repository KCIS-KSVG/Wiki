# 01.05 什么是 RAW 照片

## 核心概念概述

RAW 并非一个英文单词，而是一个技术缩写。在不同语境下，它被解释为“原始数据”或“未经加工的生材料”。在数码摄影中，RAW 指的是相机图像传感器输出的、未经图像处理器（ISP）完整处理的原始数据文件。

RAW 文件记录了传感器上每个像素点捕捉到的原始亮度数值，以及相机型号、镜头参数、色温设定、ISO 值等元数据。它相当于胶片时代的“底片”——保留了最完整的影像信息，供后期在电脑上进行深度调整。与相机直出的 JPEG 不同，RAW 文件并非一张“成品照片”，而是一个“数据包”。

## 一、RAW 文件的技术结构

### RAW 包含哪些数据

一个标准的 RAW 文件内部包含三部分核心数据：

传感器原始像素值：每个像素点记录的亮度数值（ADU值），未经去马赛克、白平衡、色彩映射等处理。这些数值以线性 Gamma 形式存储，与人眼感知的非线性亮度曲线不同。

元数据（EXIF / XMP）：包括相机型号、镜头型号、焦距、光圈、快门速度、ISO、色温设定、日期时间等拍摄参数。这些信息在后期软件中可以被读取和修改。

预览图（JPEG 缩略图）：相机在生成 RAW 文件的同时会嵌入一张小尺寸 JPEG 预览图，用于在相机屏幕上快速回放。这张预览图已经经过机内 ISP 处理，因此相机屏幕上的“照片”看起来是彩色的、经过调色的，而 RAW 原始数据本身是“灰色”的。

### RAW 的位深优势

RAW 文件通常以 12-bit 或 14-bit 位深存储，少数高端机型支持 16-bit。这意味着每个像素点记录了 2^14 = 16384 级亮度灰阶，或 2^16 = 65536 级。

相比之下，JPEG 格式仅支持 8-bit 位深，即每个颜色通道仅有 256 级亮度级别。位深差异带来的直接影响是：RAW 文件在高光过渡和暗部细节中拥有更平滑的渐变，后期大幅调整曝光或对比度时不容易出现色阶断裂（色彩断层）。

## 二、RAW 与 JPEG 的本质差异

### 色彩空间与白平衡

RAW 文件本身没有固定的白平衡值。相机在拍摄时记录的色温设定只是一个“标签”，后期软件中可以随意更改而不会损伤画质。

JPEG 文件的白平衡在拍摄时已经“烘焙”进了图像数据中，后期修改白平衡相当于对已有的 RGB 数值进行重新映射，调整幅度有限且可能产生色偏。

### Gamma 曲线与动态范围

RAW 文件以线性 Gamma 存储，即像素亮度值与光子数量呈正比关系。人眼对暗部的变化更敏感，因此最终显示时需要应用非线性 Gamma 曲线进行映射。

JPEG 在相机内已经应用了标准的 Gamma 曲线，高光和暗部都被“压缩”以适应显示设备的动态范围。这意味着 RAW 文件保留了更宽广的动态范围，高光溢出和暗部死黑可以通过后期软件“拉回”到可见范围。

### 有损压缩与无损存储

RAW 文件通常采用无损或轻微有损压缩，保留传感器输出的全部有效数据。

JPEG 则采用有损压缩算法，通过丢弃人眼不敏感的高频细节来减小文件体积。每次保存 JPEG 都会重新压缩，累积损失不可逆。

| 对比维度 | RAW | JPEG |
| :--- | :--- | :--- |
| 位深 | 12-bit / 14-bit / 16-bit | 8-bit |
| 亮度灰阶 | 4096 至 65536 级 | 256 级 |
| 白平衡 | 可完全重设，无损画质 | 拍摄时固定，调整受限 |
| 动态范围 | 保留完整传感器数据 | 已压缩，高光暗部恢复有限 |
| 压缩方式 | 无损或轻微有损 | 有损压缩，体积小 |
| 后期空间 | 极大，可大幅调整曝光与色调 | 有限，大幅调整易产生断层 |
| 文件体积 | 较大（单张 30-120MB） | 较小（单张 5-15MB） |

## 三、RAW 格式的核心优势

### 曝光补偿的强大弹性

RAW 文件在线性 Gamma 下记录了传感器接收到的全部亮度信息。后期软件中调整曝光补偿时，本质上是对这些原始数据进行重新映射。在 ±2EV 范围内的曝光调整，RAW 文件几乎不会损失画质。

JPEG 文件的曝光调整则是基于已经应用过 Gamma 曲线的数据，暗部提亮时噪点明显增加，高光压暗时容易出现灰色断层。

### 色温与色调的自由控制

拍摄时错误的色温设定在 RAW 文件中只是一条可修改的元数据记录。后期软件中可以随意调整色温和色调滑块，效果等同于在拍摄时重新设定白平衡。

JPEG 的色温信息已经融入到 RGB 像素数据中，后期调整等价于对已确定的颜色进行扭曲，色彩准确性和自然度都明显下降。

### 非破坏性编辑流程

RAW 编辑软件通常采用非破坏性编辑模式——所有调整参数以指令集形式存储，不直接修改原始 RAW 数据。导出 JPEG 或 TIFF 时再将这些指令应用到原始数据上生成最终图像。

这意味着你可以随时回到原始 RAW 文件重新调整，不会因为“保存”而丢失底层数据。

## 四、RAW 格式的劣势与限制

### 文件体积与存储压力

RAW 文件体积较大。一张 2400 万像素的 RAW 照片约 30-50MB，5000 万像素机型则可达 80-120MB。在连续拍摄数百张的活动场景中，存储卡容量和电脑硬盘空间需要提前规划。

### 后期工作流的效率代价

RAW 文件需要经过专门的软件才能查看和编辑，无法在文件管理器中直接预览（需安装编解码器）。批量处理 RAW 文件对电脑的性能要求较高，处理时间远长于 JPEG。

### 兼容性与分享不便

RAW 文件格式因相机品牌而异，不同品牌之间互不兼容。早期版本的后期软件可能无法解码新型号相机的 RAW 文件，需要等待软件更新。RAW 文件无法直接发送给他人或在社交媒体上发布，必须导出为 JPEG 或 PNG。

## 五、何时选择 RAW，何时选择 JPEG

**应选择 RAW 的场景：**

- 混合光源环境，色温难以在拍摄时精确判断（如室内投影+暖色面光混合）
- 高反差场景，需要尽可能保留高光和暗部细节
- 商业拍摄或重要活动，画质要求高且后期调色空间需要最大化
- 需要大幅输出或后期裁剪重新构图的场景

**可以选择 JPEG 的场景：**

- 日常记录、旅行随拍，对画质要求不高
- 存储卡容量紧张，需要拍摄大量照片
- 需要快速交付成片，无需后期精修
- 网络分享或社交媒体发布，文件体积需要尽量小

::: tip 💡 现场经验
在混合光源环境中，专业团队会优先选择 RAW 格式。阶梯教室中投影屏幕的光源偏冷（约 6000K-8000K），而现场面光灯通常为暖色（约 3200K-4500K）。若使用 JPEG 拍摄，色温被“烘焙”进文件，后期难以兼顾两种光源的肤色准确度。RAW 则允许后期软件对画面不同区域分别调整色温，获得更自然的肤色还原。
:::

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：RAW 文件看起来“灰”是因为相机坏了或设置错误。**

RAW 文件的“灰”是其物理特性——线性 Gamma 数据未经 ISP 映射为显示曲线，同时未应用白平衡和色彩矩阵。这种外观是正常现象，导入后期软件后会自动应用色彩映射呈现正常颜色。

**误区二：拍摄 RAW 可以在后期随意调整曝光，拍摄时不需要准确曝光。**

虽然 RAW 提供了较宽的曝光调整弹性，但过度欠曝或过曝的 RAW 文件仍然无法完全恢复。传感器在低光区域存在读出噪点，过度提亮会放大噪点；高光区域一旦超过像素井满阱容量，信息永久丢失。RAW 的意义在于提供“更宽容的容错空间”，而非“不需要正确曝光”。

**误区三：只要保存为 RAW 格式，画质就一定比 JPEG 好。**

RAW 仅保留了原始数据，若镜头光学素质差、拍摄时对焦不实、快门速度不足导致运动模糊，这些物理缺陷无法通过 RAW 格式弥补。RAW 的优势体现在“后期调整空间”，而非直接提升图像锐度或分辨率。
:::

## 总结

RAW 格式是专业摄影工作流中不可或缺的工具。它以更大的文件体积和更复杂的后期流程，换取了白平衡无限制调整、曝光大幅补偿和动态范围最大化保留的核心优势。

理解 RAW 与 JPEG 的本质差异，能帮助你在不同拍摄场景中做出合理的格式选择，平衡画质需求与工作效率。
