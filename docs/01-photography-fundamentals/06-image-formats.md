# 01.06 JPEG、RAW、HEIF 格式区别

## 核心概念概述

现代数码相机通常提供多种图像格式选项。最常用的三种是 JPEG、RAW 和 HEIF。它们各自采用不同的压缩算法、色彩采样方式和位深，直接影响最终照片的画质、文件体积和后期处理空间。

理解这三种格式的技术差异，能够帮助你在不同的拍摄场景中做出合理的格式选择——是优先保证画质和后期灵活性，还是优先保证存储效率和快速交付。

## 一、三种格式的基本定位

JPEG 是有损压缩格式，诞生于 1992 年，是目前最普及的图像格式。它在画质和文件体积之间取得了较好平衡，几乎所有设备原生支持，适合日常拍摄和快速分享。

RAW 是相机传感器原始数据，未经完整图像处理。它保留最完整的影像信息，后期调整空间最大，但文件体积大、兼容性较差，需要专门软件处理。

HEIF 是新一代图像格式，由 MPEG 组织于 2015 年推出。它使用更先进的 HEVC 压缩算法，在同等画质下文件体积约为 JPEG 的一半，支持更高位深和透明通道，已被苹果、佳能、索尼等厂商采用。

## 二、核心参数对比

| 对比维度 | JPEG | RAW | HEIF |
| :--- | :--- | :--- | :--- |
| 压缩方式 | 有损压缩 | 无损或轻微有损 | 有损压缩（算法更先进） |
| 色深 | 8-bit | 12-bit / 14-bit / 16-bit | 8-bit / 10-bit / 12-bit |
| 色彩采样 | 4:2:0（多数） | 4:4:4（全采样） | 4:2:0 / 4:2:2 / 4:4:4 |
| 文件体积 | 较小 | 很大 | 极小 |
| 后期调整空间 | 有限 | 极大 | 中等 |
| 设备兼容性 | 极好 | 需要专门软件 | 较新设备支持 |
| 适用场景 | 快速交付、网络分享 | 专业后期、重要拍摄 | 高效存储、HDR显示 |

## 三、色彩采样

色彩采样是指图像在压缩时对颜色信息进行降采样的方式。人眼对亮度细节敏感，对颜色细节相对不敏感，因此压缩算法可以在不明显影响视觉质量的前提下降低颜色数据的采样率。

4:4:4 代表无色彩采样，亮度和颜色信息全部保留。4:2:2 代表水平方向颜色信息减半。4:2:0 代表水平和垂直方向颜色信息都减半。

RAW 文件通常记录完整的 4:4:4 色彩信息，配合高色深，为后期调色提供了最大的数据基础。JPEG 通常采用 4:2:0 采样，以牺牲颜色细节换取更小的文件体积。HEIF 则可根据设置选择 4:2:0 或 4:4:4，灵活性更高。

## 四、各格式的适用场景

### JPEG：通用性与效率优先

JPEG 的优势在于通用性。任何设备、任何软件、任何网页都能打开 JPEG 文件，无需安装编解码器。拍摄后即可直接分享，无需任何后期处理。

JPEG 适用于日常记录、旅行随拍、社交媒体分享、快速交付给客户预览等场景。当存储空间有限或需要拍摄大量照片时，JPEG 是合理选择。

### RAW：画质与后期空间优先

RAW 的优势在于无损保留传感器全部数据。后期可以大幅调整曝光、色温、色调和高光阴影细节，而不损失画质。

RAW 适用于重要活动、商业拍摄、混合光源环境、需要后期精修或大幅输出的场景。当拍摄条件不理想（如光线复杂、色温不确定）时，RAW 能提供最大的容错空间。

### HEIF：新一代高效格式

HEIF 的优势在于更高的压缩效率。同等画质下文件体积约为 JPEG 的一半，同时支持 10-bit 色深，能够呈现更平滑的色彩过渡，特别适合 HDR（高动态范围）图像显示。

HEIF 适用于存储空间紧张但不愿牺牲画质的场景，以及需要拍摄 HDR 照片并在 HDR 屏幕上展示的场合。苹果 iPhone 自 iOS 11 开始默认使用 HEIF 格式，佳能、索尼等相机品牌也陆续加入支持。

## 五、存储卡紧张时的格式选择策略

在需要长时间连续拍摄且无法更换存储卡的情况下，合理选择格式至关重要。

优先保证数量的策略：选择 JPEG 精细模式，体积可控且无需后期，适合以“拍到”为最优先的场景。

优先保证关键素材质量的策略：选择 RAW 拍摄最重要环节（如颁奖、致辞核心时刻），其余场景切换为 JPEG。部分机型支持同时记录 RAW+JPEG，但在存储卡紧张时不建议开启。

平衡策略：选择 HEIF 格式（若设备支持），在同等画质下获得更小的文件体积，兼顾质量和数量。

::: tip 💡 现场经验
在低规格多机位项目中，专业团队会根据活动时长和可用存储卡容量提前计算格式选择。若预估录制时间较长且无法中途换卡，会在非核心环节采用 JPEG 格式以延长续航，并在主持人串场或转场间隙更换存储卡。关键仪式环节则切换回 RAW 或 RAW+JPEG 以确保画质。
:::

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：HEIF 格式一定会取代 JPEG。**

HEIF 在压缩效率和色深支持上确实优于 JPEG，但其普及受限于设备兼容性。老旧设备、网页浏览器、社交平台对 HEIF 的支持仍不完善。在可预见的未来，JPEG 仍将是最通用的图像格式。

**误区二：拍摄 RAW 就一定比 JPEG 好。**

RAW 的优势体现在后期处理空间，但如果你的工作流不涉及后期精修（如新闻快讯、实时直播封面），RAW 反而会拖慢交付效率。根据实际需求选择格式，而非盲目追求最高规格。

**误区三：HEIF 与 HEIC 是两种不同的格式。**

HEIC 是苹果公司在 HEIF 标准基础上封装的扩展名，本质上是同一技术标准。HEIC 文件可以在苹果设备间无缝流转，但在 Windows 或 Android 设备上可能需要安装编解码器才能查看。
:::

## 总结

JPEG、RAW 和 HEIF 各自定位不同。JPEG 胜在兼容性与效率，RAW 胜在画质与后期空间，HEIF 胜在压缩效率与 HDR 支持。

合理的选择逻辑是：日常快速分享用 JPEG，重要场景追求画质用 RAW，需要高效存储但不想牺牲画质时考虑 HEIF。理解三者的技术差异，能帮助你在存储空间、画质需求和工作效率之间找到最佳平衡点。
