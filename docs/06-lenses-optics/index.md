# 06 镜头系统与光学知识 概述

## 本章定位与学习目标

镜头是相机系统的“眼睛”。它不仅决定了进入相机的光线质量，更直接影响了画面的视角范围、空间压缩感、透视关系和背景虚化效果。

理解镜头的光学原理与分类特性，是选择合适的镜头完成拍摄任务、实现预期视觉效果的前提。本章将系统讲解镜头的核心参数与各类镜头的适用场景。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 焦距与视角的匹配逻辑

焦距决定了镜头能够“看到”的范围。广角适合大场景和近距离拍摄全景，标准焦段适合日常记录，长焦适合远距离特写。

### 光圈与镜头素质的关联

大光圈镜头不仅通光量大，还在暗光环境中提供更快的快门速度和更浅的景深。恒定光圈变焦镜头在整个变焦范围内保持最大光圈不变，在多机位统一参数时具有优势。

### 镜头选择服务于拍摄意图

镜头选择应优先考虑拍摄场景的需求，再考虑预算和便携性等限制条件。

## 学习路径建议

建议按照06.01至06.07的顺序逐篇推进。先建立镜头结构和焦距的理论基础，再了解各焦段镜头的具体特性。

完成本章学习后，你将能够根据拍摄场景和创作需求选择合适的镜头，并理解不同镜头对画面视觉效果的影响。
