# 06.02 焦距与视角变化

## 核心概念概述

焦距是镜头最核心的规格参数。它决定了镜头能够捕捉的视角范围——焦距越短，视角越广，画面容纳的内容越多；焦距越长，视角越窄，画面容纳的内容越少，但远处被摄体在画面中的比例更大。

理解焦距与视角的关系，是选择合适镜头完成拍摄任务的基础。错误的焦距选择可能导致画面主体过小、构图局促或无法在有限距离内拍全所需内容。

## 一、焦距的定义

焦距是指镜头的光学中心到图像传感器平面的距离，单位为毫米。焦距决定了两件事：视角大小——焦距越短视角越广，焦距越长视角越窄；放大倍率——焦距越长，远处物体在画面中的成像越大。

| 焦距范围 | 视角（约） | 分类 | 典型应用 |
| :--- | :--- | :--- | :--- |
| 14-24mm | 84-114度 | 超广角 | 风光、建筑、大场景 |
| 24-35mm | 63-84度 | 广角 | 室内全景、大合影 |
| 35-50mm | 46-63度 | 标准视角 | 日常记录、会议全景 |
| 50-85mm | 28-46度 | 中焦 | 人像、半身特写 |
| 85-135mm | 18-28度 | 中长焦 | 舞台特写、体育 |
| 135-200mm+ | 8-18度 | 长焦 | 远距离特写、野生动物 |

## 二、焦距与视角的物理关系

### 视角的数学关系

视角与焦距呈反比关系——焦距增加一倍，视角约减少一半。焦距从24mm变为50mm，视角约从84度减少至46度。焦距从50mm变为200mm，视角约从46度减少至12度。

### 传感器画幅的裁切效应

相同焦距在不同画幅传感器上呈现的等效视角不同。全画幅传感器为1.0倍基准。APS-C画幅的裁切系数约为1.5倍（尼康/索尼/富士）或1.6倍（佳能）。M4/3画幅的裁切系数为2.0倍。

等效焦距 = 物理焦距 × 裁切系数。50mm镜头在APS-C机身上等效约75mm视角，在M4/3上等效100mm视角。

## 三、焦距对画面效果的影响

### 空间压缩感

长焦镜头会将前景与背景之间的空间距离“压缩”，使远处的物体看起来比实际更近、更大。背景和主体在画面中的相对比例被放大。

### 透视关系

广角镜头强化了“近大远小”的透视效果，靠近镜头的物体被放大，远离的物体被缩小，增强了画面的纵深感。长焦镜头弱化了透视效果，使远近物体的大小关系趋于一致。

### 背景虚化能力

同一光圈和主体大小下，长焦镜头的背景虚化能力显著强于广角镜头。长焦镜头因视角窄、景深浅，背景模糊程度更高。

## 四、不同场景的焦距选择

**室内会议与阶梯教室（全景）：** 选择24-35mm广角端拍摄全场大景，交代场地环境和人员分布。注意检查是否能在有限空间内拍全所需内容——若通道距离不足，需使用更广的焦距。

**舞台演出（固定机位全景）：** 选择24-50mm标准变焦范围拍摄舞台全景，完整呈现舞台布景、灯光和表演者分布。需在彩排时确认焦距是否覆盖整个舞台宽度。

**体育赛事（室内运动）：** 选择70-200mm长焦镜头拍摄中远距离对抗画面。室内体育馆空间有限，70-200mm足以覆盖半场范围的运动员特写和对抗画面。

**人像与特写（活动拍摄）：** 选择50-85mm中焦段拍摄人物特写，既避免广角产生的透视变形，又能在近距离内获得自然的背景虚化和空间压缩感。

**户外大场景（校庆、运动会）：** 选择24-70mm标准变焦覆盖广角到中焦全景和舞台近景，配合70-200mm长焦捕捉运动员特写和领导致辞瞬间。

## 五、焦距与安全快门

焦距越长，手持拍摄所需的最低快门速度越高（以控制手震模糊）。安全快门速度 ≈ 1/等效焦距。全画幅50mm的安全快门约为1/50秒，APS-C等效75mm的安全快门约为1/75秒，200mm的安全快门约为1/200秒。

在光线不足时使用长焦镜头，应提高ISO或使用三脚架来补偿。

## 六、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：焦距越长的镜头就一定越好。**

长焦镜头在拍摄远处主体时有优势，但在近距离或狭小空间内无法使用。不同焦距对应不同拍摄需求，不存在“最好”的焦距。

**误区二：APS-C机身使用全画幅镜头时焦距会改变。**

焦距是镜头的物理属性，不会因机身而改变。改变的是视角——APS-C传感器只利用了镜头成像圈的中央部分，等效视角变窄。

**误区三：广角镜头适合拍摄所有大场景。**

广角镜头虽然能拍下更多内容，但强烈的透视畸变会使画面边缘产生拉伸变形，在拍摄人物合影时，边缘人物会被拉宽变形。大场景拍摄应根据主体位置和构图需求选择合适焦距。
:::

## 总结

焦距决定了镜头的视角和放大倍率。短焦距提供宽广视野，适合大场景和近距拍摄；长焦距提供窄视角和空间压缩，适合远距离特写和体育赛事。理解焦距与视角的对应关系，是在各类拍摄场景中选择正确镜头的第一步。
