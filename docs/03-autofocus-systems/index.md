# 03 相机对焦系统 概述

## 本章定位与学习目标

对焦是决定画面清晰度的核心环节。一张照片无论曝光多么准确、构图多么精妙，若焦点不实，所有努力都将付诸东流。

现代相机的对焦系统经历了从手动到自动、从单点到智能追踪的巨大演进。本章将系统讲解自动对焦的物理原理、各种对焦模式的特点与适用场景、以及人眼识别、AI 追踪等前沿技术的底层逻辑。

## 理论知识在现实拍摄中的应用

在正式阅读各子文章之前，我们可以从实际拍摄场景中建立三个贯穿本章的核心认知。

### 对焦模式的选择逻辑

固定机位拍摄（如舞台全景、会议全景）使用手动对焦最为可靠。一旦锁定焦点，画面全程清晰，不存在镜头反复搜索的隐患。

手持拍摄静态主体（如人像、风光）使用 AF-S 单次对焦，半按快门合焦后重新构图，精度高且操作直观。

手持拍摄运动主体（如体育赛事、奔跑儿童）使用 AF-C 连续对焦，相机持续追踪被摄体的距离变化，确保每一帧都清晰。

### 对焦点的选择与构图的关系

现代相机提供数十甚至数百个对焦点。在拍摄中，应主动选择靠近主体的对焦点，而非依赖中央对焦后重新构图。中央对焦后平移构图在大光圈浅景深下可能导致焦点偏移。

### 对焦辅助工具的合理使用

峰值对焦和放大对焦是手动对焦场景下的重要辅助工具。峰值对焦通过高亮边缘显示合焦区域，适合快速操作；放大对焦提供像素级精度，适合微距和星空等要求极致精度的场景。

::: tip 💡 现场经验
在室内音乐厅固定机位拍摄时，专业团队会在彩排期间完成手动对焦设定，利用放大对焦功能精确锁定舞台中央演员的面部，然后用胶带固定对焦环，确保整场演出过程中焦点纹丝不动。若使用自动对焦，舞台追光变化或演员大幅移动都可能导致镜头“拉风箱”，造成数秒的失焦画面无法使用。
:::
