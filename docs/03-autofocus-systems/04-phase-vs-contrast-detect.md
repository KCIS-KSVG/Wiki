# 03.04 相位检测 vs 对比度检测

## 核心概念概述

自动对焦系统的核心是测距技术。目前主流相机采用两种测距原理：相位检测和对比度检测。两者在速度、精度、工作原理和适用场景上存在显著差异。

绝大多数现代相机采用混合对焦系统——同时搭载两种技术，取长补短。理解两者的本质区别，有助于在不同拍摄场景中选择合适的对焦方式。

## 一、相位检测对焦

### 工作原理

相位检测对焦的原理类似于测距仪。它将进入镜头的光线分为两束，分别投射到两个成对排列的感光像素上，形成两个图像。通过分析两个图像的“相位差”（即错位距离），处理器即可计算出被摄体的距离和镜头需要移动的方向与幅度。

这一计算过程只需要一次检测即可得出结果，因此相位检测对焦速度极快，且能够判断镜头应该“往前”还是“往后”移动，无需反复搜索。

### 实现方式

在单反相机中，相位检测像素位于独立的对焦传感器模块上，通过副反光镜接收部分光线。在微单相机中，相位检测像素直接集成在图像传感器上（称为片上相位检测），覆盖画面的大部分区域。

| 对比维度 | 独立相位检测（单反） | 片上相位检测（微单） |
| :--- | :--- | :--- |
| 覆盖范围 | 集中在画面中央区域 | 覆盖大部分画面区域 |
| 对焦速度 | 极快 | 极快 |
| 低光性能 | 受独立传感器性能限制 | 受主传感器性能影响 |
| 对焦偏移风险 | 有（光路差异导致） | 无（对焦与成像同光路） |

## 二、对比度检测对焦

### 工作原理

对比度检测对焦直接利用图像传感器接收到的画面数据进行分析。处理器驱动镜头从当前焦点位置开始前后移动，同时分析画面中选定区域的对比度变化。

当对比度达到最大值时，画面最清晰，即完成合焦。这一过程类似于“爬山算法”——不断寻找对比度最高的位置。

### 核心特点

对比度检测对焦不依赖额外的对焦传感器，利用主传感器即可实现，系统结构简单。在小光圈或镜头最大光圈较小时仍可工作，且精度极高，适合微距和静态场景。

其主要劣势是对焦速度较慢，镜头需要前后搜索才能确定峰值位置，无法判断方向。在视频拍摄中，反复搜索导致可见的对焦呼吸效应，且低对比度场景（纯色墙壁）无法找到足够的对比度变化，可能完全无法合焦。

## 三、两种技术的性能对比

| 对比维度 | 相位检测 | 对比度检测 |
| :--- | :--- | :--- |
| 对焦速度 | 极快（一次测距即完成） | 较慢（需往返搜索） |
| 对焦精度 | 较高 | 极高（微距场景最优） |
| 运动追踪 | 优秀（可预测运动方向） | 较差（滞后明显） |
| 低光表现 | 较好（需要足够光线） | 较差（对比度下降） |
| 视频对焦 | 优秀（响应快） | 较差（呼吸效应明显） |
| 系统复杂度 | 较高（需要专用像素） | 较低（利用主传感器） |

## 四、混合对焦系统

现代绝大多数微单相机采用混合对焦系统：以片上相位检测像素为主体提供快速对焦和运动追踪能力，在需要极致精度的场景（如微距）由对比度检测进行最终合焦确认。

两种技术在实际工作中的分工如下：

- 相位检测负责初始测距和快速合焦，获取目标距离和镜头移动方向。
- 对比度检测进行最终合焦确认，验证相位检测的合焦精度并进行微调。
- 在低光或低对比度场景中，若相位检测无法工作，系统自动切换至对比度检测。

## 五、实战中的对焦技术选择

**体育赛事与动态抓拍：** 优先依赖相位检测。速度和追踪能力是决定性因素，对焦精度要求相对宽松。使用 AF-C 模式，让相位检测持续追踪运动主体。

**人像摄影（大光圈）：** 混合系统协同工作。片上相位检测快速合焦，对比度检测确认眼部精度，确保浅景深下眼睛精确合焦。

**微距与静物：** 建议切换至对比度检测为主或直接使用手动对焦+放大辅助。极致精度优先于速度。

**视频拍摄：** 优先使用相位检测。快速响应避免呼吸效应，配合人脸/眼部追踪保持主体合焦。

## 六、知识拓展

**交叉型对焦点与十字型对焦点：** 相位检测对焦点分为水平和垂直两种检测方向。仅检测单一方向的对焦点称为线型对焦点，同时检测水平和垂直两个方向的对焦点称为十字型对焦点。十字型对焦点对横竖线条都敏感，精度和可靠性更高，通常位于画面中央区域。

**对焦像素的成像影响：** 片上相位检测像素会占用部分成像像素的位置。虽然通过插值算法可以弥补缺失的成像信息，但极端条件下可能产生微弱的“网格状”画质影响。索尼、佳能等厂商通过像素共享和算法优化持续降低这一影响。

## 七、常见误区与避坑指南

::: warning ⚠️ 避坑指南

**误区一：相位检测一定比对比度检测更先进。**

相位检测在速度和追踪上占优，但对焦精度可能不如对比度检测。在微距或需要极高精度的静态场景中，对比度检测往往更可靠。两者是互补关系，而非替代关系。

**误区二：低光环境下切换至手动对焦就可以解决问题。**

手动对焦在低光下同样困难——人眼可能看不清细节。正确的做法是使用对焦辅助灯或用手电照亮主体辅助合焦，合焦后切换至手动锁定焦点再关闭辅助光。

**误区三：对焦速度只取决于对焦技术，和镜头无关。**

对焦速度受镜头马达类型、镜片重量、对焦镜片组移动范围等多重因素共同影响。高性能机身搭配慢速镜头，对焦速度依然受限。选购时应考虑机身与镜头的协同匹配。
:::

## 总结

相位检测与对比度检测是两种互补的对焦技术。相位检测擅长速度与追踪，适合动态场景；对比度检测擅长精度，适合静态场景。现代混合对焦系统将两者结合，在大多数场景下实现了速度与精度的平衡。
